## 本阶段试玩

1. 首次启动选剧本与势力；之后可在「菜单 → 新游戏 / 选择势力」重新选择。
2. 底部「城市」优先列出己方城池，点击后放大定位。点己方城池即可征兵、训练、生产和出征。
3. 点己方部队，先点固定底栏「行军」，再点地图目标查看路线，用底栏「开始行军」确认，远程目标逐旬自动前进，支持改道/停止；点射程内敌军普攻，点射程内敌方城池攻城，点相邻己方城池回城。弩兵可隔一格普攻，投石与舰船使用各自射程；移动需确认路径并消耗有限预算，移动后仍可攻击、战法、计略、入城或待命；这些命令结束完整行动。
4. 「下一旬」执行其他存活势力的电脑行动，然后结算粮草、收入并恢复我方行动。结算在后台快照执行，期间阻止重复操作。
5. 「菜单 → 保存局面 / 读取存档」支持3个手动槽。自动存档在成功操作和进入后台时更新；当前写入v22，能读取v1～v21旧存档，旧手动槽对应现在的槽1。
6. 己方城池「内政」开发设施和巡察，「调动」派遣人员或运输，「任务」查看改道/返回，点击设施可取消/拆除。
7. 城池「武将」可搜索、登用、褒奖、任命太守；概览「人事 / 城市治理」可查看本城状态。武将一览提供姓名、势力、城市、能力排序与在野筛选。
8. 「军事」征兵时显示本城剩余兵源，选择武将后预览实际征兵/训练效果；太守、治安会影响真实月收入。
9. 选择己方部队后，「战法」按兵种及B/A/S适性列出可用招式，「部队计略」提供火计、灭火、扰乱、伪报、镇静和伏兵；执行前显示消耗与成功率。
10. 城池概览「外交 / 协定」可亲善、流言、缔结或解除协定，以及请求援军、劝降、交换俘虏；协定在双方行动及持续伤害中生效。「内政 → 商人 / 粮食买卖」按本旬报价交易粮食。
11. 城池概览「技巧 / 培养」安排研究或武将培养；「任务 → 筛选 → 研究 / 培养」查看进度。占用武将到期后回到可用状态，研究效果和适性提升保存到局面。
12. 「内政 → 设施开发」直接建最高级，地图高亮选址；造币与谷仓影响相邻设施收益。「军事」可修复城防。军事设施由携金部队在邻接地块设置，施工占用行动，可中止或继续补修；建成后开始生效。
13. 「军事 → 编队 / 水陆出征」选择主将、至多两名副将、陆战兵装、舰船、携粮和携金；出征后直接选中部队，可移动或归城。水上自动使用舰船，上岸恢复陆战兵装；登陆和出征同样遵守难所行军前置。
14. 开发工房或临水造船厂后，在「军事 → 军备制造」安排跨旬生产。「任务 → 筛选 → 军备制造」查看工期或中止；木兽须研究开发木兽，投石和斗舰由开发投石解锁。
15. 「筑垒研兵」选择工营，选中已携10000金的筑垒官部队即可设置设施。城市→研究→技巧研究按九系查看36项技巧；标准技巧点/金与前置已接入，工期和部分效果仍为工程规则。

## 工程

- `core/`：纯 Java 17 规则内核，可在没有 Android SDK 的环境测试。
- `app/`：原生 Android Java 客户端，Canvas 仅为本阶段调试地图渲染器。
- `docs/`：来源、版本边界、完整性标准、路线和当前差异。
- `.github/workflows/android.yml`：核心测试、Android 编译、Lint、安装操作测试、APK 构建产物。

本地验证：`bash scripts/test-core.sh && bash scripts/test-ui-models.sh`。

Android 构建：安装 JDK 17、Android SDK 35、Build Tools 35.0.0、Gradle 8.11.1，然后运行 `./gradlew test :core:check :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug`。已提交固定 Gradle 8.11.1 及 SHA-256 的 Wrapper。

APK 产物位于 `app/build/outputs/apk/debug/app-debug.apk`；当前CI产物名为 `sanguo11-mobile-apk`，含以提交命名的APK、BUILD_COMMIT、SHA256SUMS与签名检查记录。对应提交源码为 `sanguo11-mobile-source`；`android-smoke-evidence` 包含操作截图与日志。v0.9起沿用固定公开开发证书及 `game.sanguo.mobile.dev` 包名；正式发行应使用独立、妥善保管的发行密钥。
