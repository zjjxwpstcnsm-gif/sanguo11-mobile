# sanguo11-mobile

独立运行的 Android 三国回合制策略游戏工程，最终目标参照 **PC《三国志11＋威力加强版》** 的完整系统范围。横屏、中文、离线游玩；不依赖模拟器、原版可执行文件或远程串流。

## 当前状态

**M0：规则基础验证版。不是完整复刻，不代表已经掌握或还原全部原版规则。**

本阶段提供六角格地图、地形寻路、城池资源、征兵与训练、兵装生产、出征、移动、普攻、攻城、回合补给、简单电脑对手、胜负判定、版本化存档及 Android 触控界面。测试地图只有 3 座城、6 名武将，兵种仅开放枪、戟、弩、骑四类。测试数值、城市位置、伤害公式和 AI 均为独立编写的工程样例，**不能当作原版数据**。

最终要求仍包括全武将、全兵装/战法、全城池/港口/关隘、全国地图、剧本、内政、人事、外交、计略、单挑、舌战、技巧、能力研究、特技、事件、编辑器与完整胜负流程。详见 [功能覆盖表](docs/FEATURES.md)。

## 本阶段试玩

1. 选择绿色的「新野」，训练、征兵或生产兵装，然后选择武将与兵种出征。
2. 点选绿色部队，点击高亮空地移动；点击相邻敌军、蓝色城池或灰色空城进行攻击。
3. 弩兵可以隔一格普攻。每支部队每旬只有一次完整行动，移动会消耗这次行动。
4. 点击「下一旬」，蓝色电脑势力行动，随后结算粮草并恢复行动。
5. 消灭敌方势力（其城池和部队均为零），或攻占全部城市且清除敌军后获胜。菜单中可以保存、读档、查看武将和重开。

这是验证操作与规则管线的测试战场，尚无原版战法、政治外交或真实剧本。

## 工程

- `core/`：纯 Java 17 规则内核，可在没有 Android SDK 的环境测试。
- `app/`：原生 Android Java 客户端，Canvas 仅为本阶段调试地图渲染器。
- `docs/`：来源、版本边界、完整性标准、路线和当前差异。
- `.github/workflows/android.yml`：核心测试、Android 编译、Lint、APK 构建产物。

本地验证：`bash scripts/test-core.sh`。

Android 构建：安装 JDK 17、Android SDK 35、Build Tools 35.0.0、Gradle 8.11.1，然后运行 `gradle :app:assembleDebug :app:lintDebug`。当前没有提交 Gradle Wrapper；CI 使用固定版本的 Gradle 安装步骤。

APK 产物位于 `app/build/outputs/apk/debug/app-debug.apk`；CI 会保存名为 `sanguo11-mobile-m0-apk` 的产物。它是开发调试签名，正式发行和后续覆盖升级前需要配置持久签名密钥。不要把密钥提交进仓库。
