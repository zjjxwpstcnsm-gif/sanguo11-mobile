CPU primitive array payload rises from 43,311,288 to 75,716,856 bytes (+32,405,568, +74.8%), because both existing near and far meshes now retain the explicit UV/tangent/auxiliary stream. This is a cost increase, not a performance PASS. The additional field and finite derivative samples explain generation work; generation stays on the existing worker and reused chunks remain stable. JVM object overhead, RSS/PSS, GPU allocations and presented frame times are not represented by these numbers. Device profiling and compact stream/dedup optimization remain acceptance work; do not call this a measured stable 30/60 FPS release.
