## Formal consumers

`SceneMesh.ground()` samples `TerrainMaterialField` on global coordinates, attaches `surfaceData`, then `detail()` interpolates all channels from the coarse triangle. Terrain-specific COLOR is four linear material weights (grass, soil, sand, rock), not an RGBA tint. Existing proxy COLOR remains unchanged.

Slot 0 remains seven floats (POSITION float3 offset 0, COLOR float4 offset 12, stride 28). Ground-only slot 1 is eight floats (UV0 float2 offset 0, TANGENTS quaternion float4 offset 8, UV1 float2 offset 24, stride 32). UV0 = canonical projected `(x,-z)` with one texture repeat per world unit. UV1 = authoritative per-cell water mask, global macro tone. No camera-relative shader position or gameplay RNG is used. Global visual seed is the fixed algorithm seed/version; mapRevision intentionally does not randomize textures.

Ground triangle order was reversed from the legacy downward-facing winding to +Y; the old unlit path hid this problem, but double-sided lit shading flips normals on a backface and contributed to invalid shading in the first native candidate. The second candidate still failed; the missing gamma encoding and UV macro bug required separate fixes. TerrainMaterialFieldTest now checks each triangle orientation against the tangent frame.

Tangent quaternion rotates +Z into normalized `(-dh/dx,1,-dh/dz)` and has positive w. Flat tangent is +X, bitangent -Z, normal +Y. Coarse frames are unit length; near vertices interpolate the exact quaternion components to preserve the same interpolated normal field at both LODs. Shader normal detail is decoded, mixed in the same tangent space, then normalized before `prepareMaterial`.

`FilamentMapView` owns one ground material/default instance and eight textures. Each texture is a full periodic layer, SRGB8_A8 albedo or linear RGBA8 normal RGB + roughness A. Full runtime mip chains, trilinear filtering and REPEAT remove atlas/independent chunk mip edges. 256² textures total about 2.67 MiB GPU storage including mips (estimate, not GPU measurement). Eight samplers leave room under GLES3 fragment sampler limits. LOW skips normal texture reads using a uniform branch but keeps the same albedo blends; other qualities use strength .65. Quality recreates the renderer through the existing path. Textures are registered for ownership immediately after creation; initialization failure uses existing release/2D recovery.

Ground lit uses the existing shadowless directional light (-1,-2,-1), 50000 lux, warm neutral color. Fixed camera exposure is f/11, 1/125 s, ISO100. When SwapChain.isSRGBSwapChainSupported(engine) is true, the display framebuffer performs linear-to-sRGB encoding with CONFIG_SRGB_COLORSPACE and post-processing stays off. This is explicitly supported by pinned SwapChain.h. Otherwise the final post-processing gamma pass is enabled. Diagnostics report the actual color path; FXAA remains disabled. Existing GLES/MSAA capability gate is untouched. Land's former CPU directional tint was removed. Existing site/unit/vegetation lighting remains S12 scope. Material is mobile OpenGL compiled by exact Filament v1.56.0 matc (`--version` 56). Runtime remains 1.56.0. See source and build instructions under tools/3d.

## Cache and geometry

Fingerprint adds TerrainMaterialField.VERSION=1 to existing dimension/projection + six-cell terrain/base/height override halo. Material support is 1.65 world units, normal central derivatives ±.25, existing height support/constraints preserved. Full rebuild versus retained chunk edits are compared in TerrainMaterialFieldTest. No geometry heights, water mask, mesh fan, ray picking, tile movement, path costs or SaveCodec changes. Water retains its exact cell coverage and a basic lit tint until S11.

Projection is planar: existing constrained slope bounds are modest; no unconditional 4-layer triplanar reads. S11 must revisit projection when introducing actual cliffs, and must preserve all global UV/weight/normal seams. No height-based layer blending is claimed: normalized compact weights plus slope exposure are used. If future height blending is added, keep a nonzero normalization fallback.

## Outstanding acceptance

Native evidence status, exact build identity and untested cases are in acceptance/s10.md. No real-device frame-time/thermal or full manual editor claim is made. S11 must not interpret a host test or emulator screenshot as physical-device certification.

CRITICAL shader contract: `flipUV : false` is explicit in ground.mat. Filament otherwise flips BOTH UV0.y and UV1.y. UV1.y is an auxiliary macro multiplier (about .96), not a texture coordinate; default flipping made it about .04 and invalidated the lighting. The compiled vertex GLSL was inspected to confirm direct mesh_uv0/mesh_uv1 forwarding. Keep this flag for future water/terrain channels.

## Blank-output recovery

Runtime1be4ddc adds asynchronous 32x32 PixelCopy checks after at least20 submitted frames and all visible chunks uploaded. At most once/second until healthy output is observed; only three consecutive nearly uniform extreme black/white results invoke existing MapHost failure recovery. Callback checks released/resumed/current SwapChain and recycles its bitmap; PixelCopy errors do not claim renderer failure. This is a conservative startup blank-output guard, not general image-quality detection. Native validation of this later change is tracked separately from the successful76eb87f SwANGLE art captures.

SwANGLE evidence uses ANGLE2.1.17841/SwiftShader5.0 Vulkan Subzero, GLES3.1, post-process gamma (sRGB SwapChain capability was false), MSAAoff. Do not equate the emulator CPU-backed renderer with phone GPU performance. The legacy SwiftShader4 driver still cannot display this material path correctly.
