## 职责与执行顺序

- World 持有单位、据点、任务和服务，协调势力阶段与全局旬。
- War/Army/Fieldworks 校验指令、支付费用并安排效果顺序；玩家与 CampaignAi 执行同一指令。
- CombatRules 只计算，包含陆战/水战基式、暴击、科技/设施/技能修正、火伤和只读预览。
- CombatEffects 应用命中；EnergyRules 统一气力上下限、实际变化与范围恢复；Government.defeated 去重后清理运输/主副将/俘虏/任务/缴获。
- Android 显示核心范围、成功概率和分项描述；不推导第二份公式。

普攻：校验→标记行动→连战判定→主伤→命中效果→击破→存续目标反击→支援→技巧奖励。战法：校验→扣一次气力/行动→命中判定→逐目标主伤/效果/击破→逐格位移、碰撞和陷阱→存续目标异常/负伤→技巧奖励。火矢物理与火伤分开；火分项不再次运行物理命中效果。城防和持续效果没有虚构部队缴获方。

全局旬保持：势力托管与各 AI 行动结束→旬号递增→对局/内政任务/技巧/持续燃烧与制造/能力研究/战略任务→火场/塔/范围恢复→城防→军政/宝物→部队供给→城内供给/收入/城防恢复→事件/生卒/外交→玩家行动重置→持续行军。

## 规则依据与边界

核对日期：2026-09-17，目标 PC PK。官方火神介绍见 [光荣](https://www.gamecity.com.tw/sangokushi/11/syou/zoom.htm?images/syou2_photo02L.jpg=)。神将/驱逐、威风、诗想/奏乐参照 [玩家考据](https://w.atwiki.jp/sangokushi11/pages/13.html)，并非原版程序逐项实测；与基线一致处不包装成新增特技。

- 神将/驱逐比较真正持有者武力与目标部队武力。相同或更低不触发；多个特技只给一次暴击。神将战法排除水军、兵器与设施；普攻条件复用驱逐。**当前 1.15 是继承工程系数，未证实原版倍率，更没有改成固定×2。**
- 威风 −20 优先扫讨 −5；当前正物理伤害触发，零伤害不触发；反击保留基线行为，精确原版反击适用性待实测。多分项中的火伤不额外扣气。
- 军乐台同势力、完成且距部队≤2；单次+10，诗想+20；多台不相加；有军乐台时不叠奏乐，无军乐台奏乐+5。现行在全局旬末恢复，原版势力阶段时点需进一步实测。刷新/加载不调用恢复。
- 火神仅火分项×2；免疫优先藤甲；藤甲易燃×2；踏破减陷阱，护卫免持续火。来源 owner/power/trap 已在 v22 持久化，服务/预览不入档。400/700/1000/1500 火伤基数、EXPLOSIVES 组合与设施耐久火伤仍是工程参数。

已有存档枚举与稳定 ID 不重排。生产模型 public 字段尚未全部封装，PK编辑、外交编队转移、反序列化仍按原路径写权威数据；本轮不引入反射、DSL、事件总线或空接口。

## 独立规则修正（非保持行为的重构）

## 性能和扩展

OfficerRoster 提供按稳定ID索引；add/set/remove/sort均失效重建，避免每个特技查询遍历全国人物。单次 Physical 评估只计算一次暴击、鼓台、阵防、科技和藤甲修正，预览端点与AI八次采样共用，返回后丢弃，不会跨移动/易主沿用。范围恢复只在旬结算查询当前设施，没有保存或界面重建时恢复。每次AI bestAction查询建立一次完成阵/鼓台的位置索引，候选只查当前位置周围最多61格；finally清除索引（含异常），下一次查询重建，所以移动、易主、拆除不需要猜测失效。单独预览只扫描当前设施一次，不跨命令保存缓存。

新增一个“正物理命中减气”特技：在稳定 Skill ID 中增加条目，在 EnergyRules.hitDrain 明确与威风/扫讨的优先级，补主副将/多目标/0伤害测试；不改 War/Army/Android。新增军乐台同类范围效果：在 EnergyRules.recovery 明确范围、阵营与叠加，若确需新建筑再追加 StructureKind（不能插队重排旧序号）及内容/图标；补移动、易主、完成、重叠和旬回放测试。新增元素伤害：在 CombatRules 增加已落实条件，在已有命令效果顺序中调用 CombatEffects；只有实际新增持久状态时才考虑保存版本。

依然未核实的原版差异：完整伤害基式与暴击系数、火科技附加常数、反击威风适用性、范围恢复精确势力时点、建筑火损、全量历史地图/人物/事件归属。参照 v0.30/v0.32 差异记录继续补齐，不宣称100%还原。

收尾审计进一步删除AI的`200+武力×2`设施估值副本和攻城旧基础值，改读同一structureDamage/siege分项，军事设施也调用正式有效性检查；火矢估值计入同一火伤与免疫，并按主伤后剩余兵力限额。这会改变AI选择，作为独立规则修正提交，不混入纯重构。

全量实装复查还发现短横屏下任务页重复标题把列表挤至零高。OverviewUi在横屏直接使用已有面板标题，给列表保留空间；原生回归实际打开制造任务详情，未改玩法或删去横屏覆盖。
