## 可操作的新增流程

- 城池「军事 → 编队 / 水陆出征」：选择一名主将、最多两名同城闲置副将、陆战兵装、舰船、兵力与携粮，最后确认才扣资源。三将共同锁定、回城与溃败统一释放。统率采用主将，武力/智力/兵科适性采用队内最高值；亲缘组合与官职统兵上限尚未实现。
- 四种基础兵装之外，增加剑兵、冲车、井阑、木兽、投石。剑兵不扣兵装，四种攻城器械每队扣一件；普通兵装按人数扣除。回城归还幸存兵对应兵装或一件器械，不能反复生成器械。
- 出征携带走舸（免费默认）、楼船或斗舰（每队一艘）。上水换用舰船移动/射程与水军适性，上岸恢复陆战兵装；两个身份同时保存在部队。水陆转换耗2移动点。骑兵、器械也能上水，山地与占格继续阻挡。战略运输暂仍采用陆路，舰船库存尚不能单独装载运输。
- 城池「内政 → 设施开发」增加工房与临水造船厂。城池「军事 → 军备制造」安排三旬一件的制造任务。木兽、投石、斗舰需要对应研究（依赖工兵育成）。制造期间锁定武将，工场拆除/城破时取消。该类库存上限100，完成时满仓保留任务等待；取消不退还费用。
- 「任务 → 筛选 → 军备制造」显示工期及中止入口。原有资源运输表单增加四种攻城器械，整批满仓等待、存读档及到达一次性入库。
- 同一地图上，冲车侧重耐久、井阑侧重守军、木兽兼顾、投石远攻。城防归零或守军归零均进入统一占领流程。冲车不能普通攻击部队。兵器/水军战法由部队「战法」进入，火矢与放射可令目标持续燃烧两旬，期间停战会抑制伤害，燃烧部队可花5气力灭火。水上撞击只作用于敌舰，岸上仍使用原12战法。
- 六类适性：枪、戟、弩、骑、兵器、水军；研究页可培养后两类。
- 新增「水陆攻防」原创沙盘：20×16、4据点、12将、2势力，开局提供器械和舰船，用于直接试玩新流程。保留原两份沙盘，无历史剧本或全国地图之声称。

## 明确的规则近似与缺口

所有新增移动、消耗、工期、伤害和成功率均为工程参数，尚未对齐原版隐藏公式。攻城器械并非原版完整升级替代关系；战法对城池目前复用普通攻城结果。没有关港水陆边界、船只建造升级转换、完整水战地形、风向、船火蔓延与物理火球。器械/水军参数由同图军备规则结算，独立战术内核新增陆战兵器档案用于适配，但并非完整水军内核。

其他重大缺口：全国格点地图、全武将/关系/生卒/特技、全历史与假想剧本、军团与独立行动力、完整技巧/能力研究树、俘虏外交、宝物、灾害/事件/继承、单挑/舌战规则、新武将/PK编辑器、决战称霸、原版AI对照。见完整功能覆盖表。

## 存档与数据

存档 v6 保持旧 v5 及更早区段的四兵装/四适性字段顺序，新增扩展区保存：额外兵装、舰船、兵器水军适性、副将、携船、燃烧、器械运输、制造任务。真实 v1～v5 存档可读；新 v6 不能用旧 APK 读取。v5 夹具在修改编码器前用原 v0.6 字节码生成，包含一支出征弩兵与进行中的适性培养。

新增剧本可选字段：`arsenals`/`arsenal.N`（城ID、冲车、井阑、木兽、投石、楼船、斗舰，共7列）；`aptitudes`/`aptitude.N`（武将ID、枪、戟、弩、骑、兵器、水军，共7列，适性0～3）。重复/不存在ID、库存/适性越界拒绝加载，原格式和旧数据哈希不变。
