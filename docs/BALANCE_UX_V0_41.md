## 攻城、野战与经营节奏

这是移动版工程平衡，不宣称为原版精确公式。

- 统一普攻、水战、器械对部队的攻防入口。统率参与攻防，武力参与攻击，适性与兵装区分角色；兵力使用平方根增长并保留伤害上限，避免人数线性碾压。
- 攻城也按兵力平方根、统率、适性缩放；普通兵种另受气力影响。器械气力决定能否施放，伤害不因预扣气力与预览产生差异。
- 相同城防下，港口耐久伤害系数 1.8，城市 1.0，关卡 0.9。城墙技巧仍增加上限，不另加隐藏减伤。
- 冲车主拆墙，井阑主杀守军；骑兵与弩兵拆墙弱于枪戟，海上高级舰船强于走舸。
- 周围三格内有敌方战斗部队即视为受围攻，自动修复暂停；和平有粮时每旬恢复 20，工兵技巧后 40；围城主动修复为平时的四分之一，费用与行动力照常扣除。
- 攻占后城防为新势力上限的四分之一，不再所有据点瞬间恢复到 1500。
- 螺旋突刺命中后普通混乱概率为 10%–40%（受双方武力差影响）；符合暴击条件时仍必定混乱。预览和 AI 使用同一概率。
- 正常攻城、器械战法、AI 评估和确认面板共用计算。破防次数是按当前兵力估算的命中数，不包括战损、补修、敌方增援或战法失败。

基准为兵力 10000、统率 80、武力 80、适性 A、气力 80、无特技/技巧，2000 城防港口：

| 场景 | 实测或计算 |
| --- | --- |
| 枪兵对港口单次城防伤害 | 483 |
| 枪兵对城市单次城防伤害 | 269 |
| 枪兵对关卡单次城防伤害 | 242 |
| 连续实际攻击港口，含据点反击 | 枪兵 5 次；冲车 2 次 |

核心回归继续覆盖金粮收支、生产与运输、军团经营和 36/72 旬长局；未为缩短攻城而同时膨胀征兵、金粮产出。

## 手机操作

空地点击后保留选中并展示地形、通行消耗和开发归属。可开发地块的“＋ 开发此地”固定在操作面板标题下，不随详情滚走；托管、非己方、满额或被占用时显示开发条件。兼容旧档与小剧本的隐式城周开发用地。

城市“出征 / 运输 / 设施开发”、港关“修复城防”、设施管理、部队就近入城与停止行军也放在固定操作区。建设仍按设施→执行武将→确认，资金不足提前提示，建设对话框根据屏幕高度调整列表并支持滚动。旬结算保留拖动、缩放地图与收起面板，游戏命令继续由正在结算的状态拦截。

## 连续地形

栈道和山径以与 Hex.neighbors 完全一致的六方向计算连接，支持直线、转弯、分叉、端点接入平地，按共享边中点对齐。道路覆盖层按 64 种邻接组合缓存，不在每帧创建图片；道路不再被格线横切。水面/海域/浅滩相互连接，仅在实际陆地边缘绘制河岸线。远景离屏缓存同步绘制道路，保持缩放后的连接关系。

边界：当前仍为原创 2D 绘制，不是完整三维地形或官方逐格美术。
