# v0.20 战果、触感与地图模型

基于 main `2b95b1a`，开发分支 `agent/battle-feedback-map-v020`。存档保持 v15，包名与公开开发签名沿用 v0.9 以来的配置。

## 本轮问题与修复

- 普通敌军部队原先没有金粮缴获结算。现在在统一溃败入口将剩余金粮移交给实际击破部队；携金上限10000、携粮上限1000000，超量明确报告遗失。守城仓库不会凭空增加，也不会把已被消灭的士兵/兵装补到胜方。运输截击同时补上缴金。
- 重复溃败回调不再重复发放金粮、功绩或改变俘虏状态。普攻、反击、支援、战法和有存活攻击者的即时陷阱击破使用相同结算；持续火伤/断粮等无可归属击破部队的损失不随机分配战利品。同势力误伤不会缴获/俘虏。
- 原本已有概率俘虏，但攻击完成时客户端不显示成功结果。现在地图下方显示可点开的战果条，列出击破部队、金粮、关押位置及逃脱武将；战报仍可查看。攻击预览逐人显示当前俘虏概率。范围伤害按每支溃败部队汇总。
- 保留原有工程概率：`clamp(20 + (攻击部队武力 - 目标武将武力)/5, 5, 60)%`，缚捕为100%；强运、血路/名马免捕优先，没有本方关押据点则不捕。主将、副将分别判定，使用可存档随机状态，预览不消耗随机数。名马免捕在掠夺宝物前确定。
- 低缩放过去会完全隐藏部队、内政设施、军事设施、火场，造成空格却阻路的错觉。现在始终保留占格标记，放大后显示模型与类型名称。绿色可达范围同样使用避火路径，避免高亮与实际自动寻路不一致。火矢杀敌仍会留下真实火场；点该格明确显示剩余旬数以及灭火/等待提示，熄灭后重新规划即可通行。
- 击破清除真实占格，并用实际命令回归验证其他部队可进入、原攻击者可预定下旬进入。攻击结束本旬行动的规则保留，路线栏会明确提示下旬出发，不再只显示“本旬0格”。

## 模型与操作

使用原创Canvas小模型：9陆战兵种、3舰船、3城关港、11内政设施、18军事设施。枪/戟/弩/剑盾、马匹、撞木/塔车/兽首/投臂，船帆及楼层、城门/城墙/码头、摊棚/田垄/筒仓/工房以及营帐/箭塔/乐台/鼓/墙/陷阱可区分。颜色表示势力，勾表示本旬行动完成。它们是简易二维立体感图形，不是精细3D模型。

「视图→兵种与建筑图例」查看说明；「视图→战斗震动」开关触感，设置在重启后保留。普攻/战法命令与击破使用不同触感事件，地图同时短暂显示冲击圈。失败命令和存档恢复不重放震动。实现参考 [Android触感事件文档](https://developer.android.com/develop/ui/views/haptics/haptic-feedback)，通过 `View.performHapticFeedback` 遵循系统触感设置，无需VIBRATE权限。具体强度依赖设备，模拟器不能验收真实马达手感。

## 规则边界

以上缴获比例（回收剩余金粮）、容量、概率与即时陷阱归属是本项目明确标记的工程实现，未声称是原版精确公式。本轮尝试取回官方PC手册失败，未据此标记新规则为“原版核验”。全量原版逐格地图、官方完整开局、全特技/PK/事件交互与精确公式仍有缺口，不能宣称100%复刻。暂不细化单挑/舌战人物模型。
