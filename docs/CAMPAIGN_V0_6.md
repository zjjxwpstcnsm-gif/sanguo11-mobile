# v0.6 军政与同图战法

## 基线与目标

本轮从 main `50f370e` 加上已验证、尚未合并的 PR #4（`aeb2aa6`）继续开发。新 PR 同时包含 v0.5 集成成果，不依赖用户先手动合并 PR #4。目标仍为 PC《三国志11＋威力加强版》的完整玩法范围。

用户本轮暂不要求单挑／舌战专用界面和人物模型；这不等于删除其规则目标。当前仍**不能称为100%还原**。以下成本、概率、适性默认值、伤害和AI均为工程规则；名称和系统种类不能代替原版公式与数据核验。

## 规则细节与边界

- 战争继续在战略地图发生，没有另造一个独立接战场景。复用 `battle.DamageCalculator` 与 `LegacyWorldBattleAdapter`；原两军 `BattleEngine` 保留原测试，未宣称它已整体替换战略地图引擎。
- 普通移动仍消耗完整当旬行动；**移动后战法的统一行动预算尚未实现**。目前仍为单主将，只有4个出征兵种；适性初始统一B级，明确不是原版武将适性数据。
- 12战法的位移效果分别实现。受阻的推击额外造成100碰撞伤害，未实现完整碰撞链。乱射仅伤交战势力；原版误射友军、暴击特技等规则尚未核对。战法成功率不是原版公式。
- 混乱跳过一次所属势力行动；伪报下次向己城退一格并跳过行动，未实现多格回撤路径。镇静清除异常，但不返还已经消耗的本旬行动。
- 火计不能针对城池／内政设施；火场不向风向自然扩散，只有火种连锁。协定势力不受主动攻击和持续火伤；自己的火仍可伤己军。箭楼每旬打一个目标。军事设施即时建造且限定城周围2～3格，不是原版部队施工。
- 同盟和停战当前共用禁止交战约束；同盟须关系至少20。尚无援军请求、俘虏谈判、劝降、联军协同或电脑主动外交。解除协定降低双方关系50、其他存活势力关系10。
- 每城每旬产10技巧点，势力每旬上限100；战斗及部分军政命令额外产点。12项研究只是技巧全集的子集。能力培养可以直接选择项目，尚无PK完整能力研究树、隐藏能力或培养次数限制。
- 设施保留每城6块沙盘限制。等级收益倍率1/1.2/1.5；造币／谷仓提供相邻50%单次加成。合并耗金200、行动力10、工期2旬。被吸收Lv1设施立即消失，施工期间目标保留原等级收益；取消保留目标、损失费用和被吸收设施。并非核验后的原版施工时序。
- 商人交易按千粮，单城每旬限额保存到存档。买卖价差防止原地循环获利，不模拟商人个体行走。
- 城破取消未完成研究和培养，不退费用；完整任务时钟只有武将的 `otherTaskTurns`，不会因为保存、恢复或多次打开面板重复完工。
- AI使用相同的战法、修城、买粮和技巧研究命令；尚无完整战略外交、特技组合、火攻部署AI。

## 100%验收仍缺失的内容

完整全国地形格点与城关港、全量武将／登场生卒／关系／适性／特技、官方剧本开局、全兵装与水军及攻城器械、三将编队、运输队拦截与水运、军团委任、全技巧和能力研究树、全部宝物与事件、单挑／舌战规则、决战称霸、寿命继承叛乱、新武将与PK编辑器，以及原版逐项公式对照和ARM真机长期验证。

没有把以上缺口改写成“已完成”，也没有用虚构全国地图或占位武将填充数量。完整功能覆盖继续由 [FEATURES.md](FEATURES.md) 管理；本轮解除的是部分系统完全缺失的状态。
