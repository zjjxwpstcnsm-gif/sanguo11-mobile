# v0.55.0 七格城市、关口与关洛精修

## 基线、边界与坐标

真实基线为 main v0.54.0 / `88768aff0def3b63500bb95b7ecc78fea84b946a`，树 `54b897bc2384a9d7306e2c1237735f3cd7180073`；地图 PR #42 已合并。全部既有地图/人物/兵种图集字节保留，构建仍验证18项美术及地图指纹。

当前正式地图继续使用 **100×100 源错行方格 + axial 六向邻接**，不是八方向寻路。七格是中心加六邻居，投影自然形成2/3/2，奇偶行通过 MapCoordinates 转换，不在 UI 硬编码。关卡与港口为一格。原图约200×200列错列，保留项目采样精度；本轮**没有原生200×200坐标迁移**。

## 正式规则链路

`SiteFootprint` 为占地、外沿、射程命中、进驻候选、出征连接、通行与范围实体去重的唯一几何入口。World.CityRoster 预索引全部占地，所有权读取实时字段，不缓存通行权限；每个City仍只有一份ID/兵粮/城防。占地类型从存档/剧本读取后显式失效索引。

Army、UnitOrders、MarchOrders 和 CampaignAi 共用移动边；己方城市每格按平地收费，不能叠兵，不自动收编。`previewMove` 表示明确行军；`previewCity` 根据指定城市实体产生进驻/攻城意图。UI常驻独立“进驻”，拖动部队与行军经过城市不会变成进驻。既有港口上下岸校验继续生效，城格不充当港口。

进驻采用Dijkstra候选目标而非中心/几何最近点；到任意合法城格或能通过真实移动边进入的相邻外缘即可一次入库。出征从锚点通过本体连通搜索真实外沿，不跨山或占位部队投放。运输仍是野战实体，不能因经过城格隐身、免疫攻击或重复交货。

普通攻城、适用的兵器/舰船战法通过存在合法命中格判定；包含最小射程及逐格限制，预览/动画/结算保持同一命中位置。共格野战部队与据点提供目标区分。落雷覆盖七格时按城市ID只扣一次城防/驻军。原来仅对部队有效的枪/戟等战法不擅自扩展为攻城战法；正常多段伤害不被修改。反击和主动守备仍按一个城市的原预算执行。

易主即时改变通行查询，旧预览拒绝执行，持续命令下一次重新寻路。处在易主城市本体的敌方野战部队保留兵粮，清除过时命令，只允许中心→外缘→城外撤出，不允许借此继续穿敌城或更深入。普通出入与相邻占兵限制不变。

MapView只画一座城市模型及连续七格基座/外墙，不复制七份图标；真实选中边界、触控、攻击高亮、小地图着色共享逻辑占地。部队在城市之后绘制。关卡缩至一格清楚表达，不能吞掉旁格点击。

## 验收

`bash scripts/test-city55.sh` 运行实际世界命令：奇偶布局、十二方向进驻、七格各自入城、三将兵粮一次入库、穿城逐格收费、真实下一旬、跨旬/存档重放、失城权限、敌/盟军、近战与弩兵、四类攻城器械、共格对象、落雷去重、运输、出征、港口、AI攻城/回城、九剧本与250剧本三旬。

关洛通路测试使用正式Army移动边，不另写规则：长安经潼关/函谷关至洛阳连通；三个关口在局部两侧、y34–42范围内关闭无绕关，开放可走。该边界是关口局部验收，**不宣称整个中国所有替代战略通路都应被一关封死**。建满591开发位后全部87据点可出征、关洛陆路保持连通；孟津临水。所有计时只是该执行环境记录，不等同于ARM手机性能保证。

Android `City55Probe` 使用实际安装APK：真实190剧本董卓开局、原地图窗口截屏、七格逐次触控、关卡邻格点选、三页签出征、城上行军、下一旬续走、显式进驻、自动存档和Activity重建。攻城专项使用250正式地图/原始势力，仅把正式出征的测试部队摆到洛阳实际外缘，明确区分布置夹具和正常游戏演练。仅API29 x86_64模拟器，未做ARM真机，也未声称所有旧单格夹具和全量历史回归通过。
