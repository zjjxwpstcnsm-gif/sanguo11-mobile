# v0.13 人物关系、宝物与PK局面编辑

基线：PR #13已核对并合并至`fc247d7963b8270c15e52140ee3940720f384697`，保留v0.12全部研究、施工和旧存档能力。**本轮仍未达到PC《三国志11＋威力加强版》100%还原。**

## 实际接入

- 人物关系按稳定ID保存父母、配偶、最多3人结义组、各最多5位亲爱/厌恶。父母图拒绝循环，配偶和结义双向一致；不从姓名或势力推断历史关系。
- 城池→武将→仲介：结义/婚姻实际消耗500技巧点，要求同城己方无任务武将、功绩至少500，结义同性、婚姻异性，拒绝血亲、厌恶、已有配偶及超额组。仲介不扣行动力。内助在婚姻成立时使双方五维各+1，上限100；重复命令不会重复增长。
- 关系影响实际编队统率/武力、普攻支援、敌将和俘虏登用、舌战登用资格以及忠诚流失。厌恶优先禁止支援；亲爱方向保留。同势力结义/配偶的登用保护在原势力仍存活时生效。
- 43件已有来源宝物取得独立运行时状态：武将持有、势力府库、据点未发现。搜索、赏赐、收回、俘获缴获、强夺、灭国府库转移与保存进入真实局面。同名大宛马/飞刀等依靠不同ID区分，不会合并或复制。
- 持有宝物动态提供名马、名剑、长柄、暗器、名弓、书籍的单挑/舌战效果。名马保护部队溃败捕获；先记录保护后结算强夺，避免被夺马同一次击破立刻失去免捕。捕获成功后转移所持宝物，不再保留重复效果。
- 玉玺每月提供技巧点；铜雀允许开发铜雀台，完成后提供月度技巧点。原有对局演练的无名装备掩码作为历史配置保留，不能冒充宝物目录中的正式分配。
- 菜单→PK编辑：编辑武将能力/适性/性别/特技/忠诚/功绩/性格/话术、据点资源/兵源/兵装/舰船、势力行动力/技巧点/技巧解锁、部队兵粮金气力/状态、人物关系、宝物位置。预览展示旧值→新值，取消不改局面；确认前整份局面已改变则拒绝过期草稿；非法输入和无变化编辑均拒绝。修改只作用当前局面并记录已编辑标记，不消耗游戏资源。
- 新武将模板支持姓名、五维、六适性、性别、特技、四性格和五话术。模板保存在应用内，可在之后的新游戏选据点/势力或在野身份登场，也可导入导出`.sgof`。新ID避开当前人物和隐藏人才；新武将能真实出征并进入存档。模板不会复制宝物、官职、功绩或旧局面身份。
- 新增“相知寻宝”原创开局，43件宝物有明确演练分配、10位原创武将及两支相邻部队，方便验证整套流程。**这不是官方剧本，也不是原版宝物开局分配。**

## 存档与兼容

写v12，读v1—v11。新增独立扩展段存人物关系、已放置宝物的定义及持有状态、编辑标记和新武将ID。已存的宝物不依赖外部目录补全其定义；旧档不凭空增加关系和宝物。旧无名对局装备继续保持原效果。新武将模板限制4KB，拒绝未知版本、截断、尾部垃圾、越界能力/适性和无效特技。

## 依据与近似

主要依据为[官方PC手册](https://cdn.akamai.steamstatic.com/steam/apps/628070/manuals/32sangokushi11wpk_manual.pdf?t=1516151052)，已检查本地PDF文字并渲染核对：正文15页铜雀台、30—32页武将和关系、39—40页赏赐/仲介、44页宝物效果，PK14—17页编辑功能。手册可确认结构、仲介500技巧及500功绩门槛、宝物种类用途、编辑对象；并没有提供所有执行公式。

[特技社区资料](https://w.atwiki.jp/sangokushi11/pages/13.html)用于补充内助双方+1、强夺、辅佐厌恶排除与名马/捕缚优先级。此来源不替代指定补丁的原版对照。

当前明确为工程参数：普通/血亲/亲爱副将优势的50%/65%/75%贡献、结义/婚姻100%；支援30%/50%及原有半伤害；登用亲爱加成10/20；宝物发现率；强夺20%；赏赐/没收按价值调整忠诚；玉玺和铜雀台每月各100技巧点。原版精确公式和舍入尚未实测，不能将这些参数宣称为核验完成。旧编队从“任何副将一律取最高武力”改为按关系贡献；智力和适性仍取编队最高值。血缘当前使用共同已记录祖先判断，不是完整原版血统/相性字段实现。
