# v0.30 地理、开发地与火系规则

## 本轮变化

- 群英汇聚、中原风云、荆襄争雄使用原始城市参考坐标比例，替换矩形随机陆地与横穿全图的单河。手工矢量化海岸、山脉、黄河、长江、汉水、淮河、湘水、赣江、洞庭及鄱阳水域；河流允许航行，陆路寻路不填平河道。地图外的非战区不参与移动或着色。
- 42城固定开发地分散在城外不同片区，持久化归属；分别有10/12/15/18/20/22块。长安与洛阳22、邺20、下邳/许昌/建业/襄阳/成都18。仍保留城门出口。建设、AI、容量校验和存读档共用这些地块。
- 曹操（魏）蓝、刘备（蜀）绿、孙氏（吴）红，地图、图例、列表图标共用颜色；加深领土填色，海面不染成领土。
- 火计/火矢/水军与兵器火攻接入即时火伤；各类火陷阱采用点火者的主副将技能。火神使火系兵力损失×2，物理箭伤单独结算；火神免火伤、藤甲火伤×2、踏破仅减陷阱火伤、护卫免持续灼烧、深谋延长火场持续时间，火神仍会受到业火种爆炸混乱；对空地无智力比较，不保证点火成功。来源倍率写入火场并随存档保存。
- 城市、武将、势力、任务概览改为卡片列表，20/50/100条分页、跳页、搜索与筛选，恢复当前页；手机默认扩大列表面板，并将武将搜索和排序合为一行。
- 点击本方空开发地，直接选择设施和执行人，最终确认开工；中途取消不消耗，旋转恢复草稿。
- 选中部队后长按拖到本旬可达格，显示路线与落点，松手移动；取消、拖出地图、小地图覆盖区及无效落点不消耗，移动后保留合法战斗指令。

- [光荣《三国志11》火神介绍](https://www.gamecity.com.tw/sangokushi/11/syou/zoom.htm?images/syou2_photo02L.jpg=)：对低智力目标火计必成、威力两倍、免疫火伤。
- [42城开发地数量表](https://www.gamersky.com/handbook/200603/21606.shtml)；[同期城市数据](https://games.sina.com.cn/j/h/2006-03-22/14133930.shtml)。
- [玩家火伤实测](https://www.bilibili.com/opus/374609164980707553)：分离即时/持续/陷阱火伤与相关技能组合。
- [公开展示的游戏地图](https://www.koubaike.com/youxi/K1JlB0rdya.html)用于视觉核对；未将原游戏图片打包为新美术。

本轮地图是依照城位与可见地形进行的手工重建，未从原游戏提取逐格地形，不能称为原版地图逐格一致；开发地数量已逐城核对，具体格位为重排。现有三个自制沙盘不是官方历史剧本。非三大势力仍使用稳定备用色，不声称所有原版势力配色都已核实。基础400点火伤、700点陷阱等工程公式及据点守军/设施耐久的火损以及尚未重审的技能仍有原版差异，不宣称全部特技完成精确还原。

## 存档与使用

固定包名与开发签名保持兼容。新写入格式v22，可读取v1–v21；真实旧v21样本回归覆盖地形、坐标、兵力与升级后再次存读。**新地形和固定开发地需要新开上述三个剧本**，读取旧存档会保留原地图与旧开发规则，避免移动或覆盖玩家的部队、设施。
