# v0.66：伤兵、据点自动入驻和势力治理

本轮从已合并 PR #56 的 main（3d9ff6734169514f3f2191a00b8f7a609649fa57）接续，不改地图格、港口位置或美术资源。以下新增数值是移动版明确采用的平衡规则，不声称为原版精确公式。

## 规则与边界

- 战斗：共享伤害入口把实际损失的 30% 累计为伤兵，小额伤害的余数保存，不能靠拆分伤害规避。伤兵不增加攻击、防御或可派遣兵力，但耗粮。粮尽逃兵不产生伤兵；整支部队溃散时不能保留零战兵的伤兵部队。主将死亡、副将接掌时伤兵继承。普通攻击、反击、战法、火和军事设施沿用共享入口。
- 据点：移动目标是己方城池七格中的任意格或港口/关卡格时自动入驻。相邻攻克也自动入驻，不要求余下移动力；远程攻克不传送。通过城市前往更远目标的路线继续穿行，即使中途在城市边缘停一旬也不吞掉后续命令。容量不够时保留原部队及全部伤兵/物资并提示，不静默删除。入驻一次性把战兵和伤兵加入守军，伤兵不凭空生产兵装，不扣兵源。
- 兵源：基础上限 20,000，每季恢复最多 5,000；每座已完成农场 +500/季，每座已完成市场 +2,000 上限。升级不按等级重复算建筑数。市场失去后超上限库存保留，但停止恢复直至低于当前上限。港口/关卡不重复拥有城池兵源。
- 批量褒奖：本城符合条件的非君主武将可多选/全选，200 金/人，一次批量行动力 10。先验证全部目标和全额资金，再一次扣费；同一武将每旬一次，重复、外出、忠诚满、已褒奖目标使整个无效批次拒绝，不部分扣款。
- 继任：自然寿终、战死、处决及流放触发统一继任流程；玩家可选继任者，AI 自动选择。原版已有的战死事件入口仍由原系统决定，未额外虚构新战死概率。与新君主相性差为 d（0–75）时降忠诚 5 + floor(d/5)，即 5–20；未知相性按 5。新君主、与新君主的配偶/义兄弟继续享有现有忠诚保护。不会把前君主的关系误当新君主关系。
- 君主爵位：只统计城池，不含港口/关卡；2 刺史、4 州牧、10 大将军、20 王、24 皇帝。基础指挥依次 10,000 / 11,000 / 12,000 / 13,000 / 14,000 / 15,000，原军事改革 +3,000 保留。保存最高已取得爵位，丢城不反复升降刷事件。皇帝在自己势力详情设置 1–8 个汉字、字母或数字的国号；不改势力 ID、外交关系、军团和行军引用。
- 太守：已有在城太守保留；空缺或太守出征、调动、出使、登用外出、被俘、死亡或改变归属时，自动取当地政治最高的现存己方武将，同政治取较小 ID。没有人就空缺。港口/关卡同样处理。当地内政和研究不算离城；旧太守回来不自动挤掉新任太守。维持君主身份，不因兼任太守降为普通武将。

## 界面

开局地图只标势力君主或国号，同势力去重，不再显示据点地名和部队标签；开局详情含军师。势力列表默认显示君主、军师、兵源、上限、季增长与爵位。武将列表默认展示身份、官职、功绩、指挥兵数、宝物数量，仍保留能力、特技、任务分组与排序/搜索。部队显示战兵和伤兵。主界面 56dp 紧凑顶栏为年月旬预留独立一行，保留行动力、战报、势力着色、视图，日期不使用省略号。

## 保存

新增 save v32 尾部扩展段保存各战斗/运输部队伤兵和小额伤害余数、各势力最高爵位和国号。读取 v31 时默认零伤兵并初始化治理；v32 同版本读取不在只读流程重复结算。更旧存档仍遵循现有 v31 基线限制，未在本轮恢复旧版地图存档兼容。
