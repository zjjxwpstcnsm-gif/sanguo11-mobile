# v0.9 军政、人事与后勤

基线：`4870f07c1916116ea7076167e4586bda4130a9cf`，PR #7、#8、#9 均已合并。目标仍为 PC PK；本轮不是全玩法 100% 复刻。

## 本轮实际接入

- 部队被物理攻击、反击、陆军/水军/器械战法击破时，主将和副将逐人结算俘虏；捕缚、强运与全队血路保护接入。火场/断粮损失不凭空指定俘获者。
- 俘虏保留原势力，不能行动、建设、调动或出征。保存关押城、俘获时间和最近招降尝试。支持招降、释放、赎回、逃脱、忠诚变化、失城转押和原势力攻城救回。存活势力君主拒绝招降。
- 40 个武官职位具有独立职位名、功绩要求、统兵上限、月俸。同势力一职一人。授官/免官、人事归属变化、被俘、俸禄不足均有实际结果。
- 城务和战斗积累功绩；任命军师、只读军师建议、从其他城池召唤武将、城池内政/守备委任。委任在玩家结束旬时使用剩余行动力和真实闲将执行一项城务，不增加资源。
- 相邻部队移交士兵/粮草；城池向相邻己军补兵补粮，扣减基础兵装。数量、归属、容量和行动均由内核校验。
- 运输队可被玩家和 AI 截击。护送兵受损、货物滞留、溃败、粮草缴获、押运武将俘获/撤退均进入实际局面。城内保护、停战/同盟保护与重复命令拒绝。
- 临水城池之间可以派遣水陆运输，实际通过水格、保存行进位置、改道、容量等待和一次性入库。陆路运输不自动变为水运。运输队不能穿过路线上的交战部队；运搬对运输速度生效。
- Android 城池概览新增「军政 / 俘虏 / 官职」，调动页新增水陆运输，部队页新增截击和兵粮移交；人物列表显示俘虏状态。原有命令入口保留。
- 存档 v8 向后读 v1～v7，新增字段放在 v7 后。新增 Android 文档选择器导入导出；先完整校验、确认后才替换局面。

## 规则证据与明确差异

军职名、功绩档和对应指挥/月俸参照[公开官职表](https://zr9558.com/2013/10/27/%E4%B8%89%E5%9B%BD%E5%BF%9711/)。捕缚/血路/强运的保护关系也参照该文。仅抽取事实，不复制攻略文字。未取得原版安装版本与补丁指纹、可执行程序对照数据。

**以下仍为工程近似，不能报原版完成：**

1. 未授官者延续旧沙盘万人上限；授官后按职位的 6000～15000 限额出征。未实现文官表、君主爵位授官解锁、爵位晋升事件、职位能力加成与原版初始任官分配。
2. 城务功绩 +100、击破功绩 +500、物理伤害/10 功绩、月俸扣款及欠薪忠诚 -2 是工程节奏；不是原版功绩/俸禄时序结论。
3. 普通部队捕获几率为 `clamp(20 + (攻击方武力 - 防守武将武力)/5, 5, 60)`；捕缚保证捕获但受已实现保护覆盖；城池守将基础 30%。未建模名马免捕、关系、性格、战死、伤病、处决或完整单挑结果。
4. 俘虏每旬忠诚 -2，后续旬 5% 逃脱，招降费用 100 且每人每旬一次。赎金按武将能力计价并直接成交；未实现对方议价、外交舌战、拒绝赎回或战俘交换。
5. 「城池委任」不是原版完整军团：未实现都督、独立军团行动力、攻城目标和军团级跨城调度。军师建议是只读规则分析，不冒充原版成功率预言。
6. 运输仍是战略任务实体，不是完整可操纵战术运输部队。被击破时能装下的粮进入袭击方，其余货物损失；不把金/兵装瞬移到己城。水陆运输使用既有工程每格费用与免费走舸概念，未实现舰船作为货物、完整岸线/关港登岸费用。ETA 不预测敌军移动。
7. 原版全国地形与完整官方开局仍为 0；670 人目录不等于全部进入可玩剧本。完整技巧树、PK能力研究、宝物、生卒关系事件、单挑/舌战规则、决战称霸仍有缺口。

## 安装与存档

新开发包 applicationId 为 `game.sanguo.mobile.dev`，与旧 `game.sanguo.mobile` 共存；Java namespace 不变。从 v0.9 起使用仓库明确公开的开发专用签名，证书 SHA256 为 `8f64ee37f8ff58de8f5a199aac2ae745a5bc927d0d0eabac7540083a5e551f24`。该密钥只用于开发包，不是正式发行身份。

新包不会读取另一个应用私有目录。旧包保留，已有 `.sg11` 文件通过新包菜单导入。旧版没有导出菜单时，可在用户自己的调试设备上通过 `adb exec-out run-as game.sanguo.mobile cat files/manual.sg11 > manual.sg11` 提取手动槽；其余文件为 manual2.sg11、manual3.sg11、auto.sg11。不要先卸载旧应用。v0.9 存档不能反向导入 v0.8。
