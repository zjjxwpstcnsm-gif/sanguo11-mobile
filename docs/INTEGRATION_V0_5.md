# v0.5 人事与治理集成

基于最新 main `50f370e504415e67209048dda5985cf94361a0c8`，整合已合并 PR #1、#2、#3。

## 本轮解决的问题

PR #3 实际只合入了编码补丁和临时交付工作流，战略源码未进入编译。此次核对原补丁 SHA-256 后恢复正式源码，删除传输文件与临时工作流，保留 PR #1 的手机导航和 PR #2 的独立战术引擎及完整测试。

原战略补丁依赖旧版菜单，无法直接套入新版客户端。本轮将人事入口接入城池概览和武将页，军事页接入实际征兵/训练预览，内政页接入巡察预览。确认框显示执行武将对应的概率、数量与资源消耗；取消不执行命令、不推进随机状态。

## 手机上如何玩

1. 新游戏选择「区域争雄 / 孙权军」，在「城市」选择柴桑。
2. 「武将 → 搜索人才」派闲将寻找人才；发现后是本城在野武将，需要另行登用。
3. 「武将 → 登用武将 / 褒奖武将 / 任命太守」选择执行者和目标。新入仕武将本旬休整；任命占用执行者和新太守的当旬行动。
4. 「军事 → 征兵 / 训练」，「内政 → 巡察」均按选定武将能力计算。征兵消耗有限兵源并降低治安。
5. 城池标题显示实际太守；概览和军事页显示兵源。武将一览可单独筛选在野武将，并显示身份、忠诚、建设/调动/运输/其他任务状态。出征状态以部队的行动标记为准。
6. 「概览 → 人事 / 城市治理 → 城市与武将状态」查看本城人员和治理收益。

规则与数值为工程实现。内置隐藏人才是明确标记的原创测试人物，不冒充原版人物数据。

## 仍然缺失

新战术引擎保留并通过测试，但尚未接入 Android 的交战界面、战略结果回写和战斗中途存档；当前 APK 普攻/攻城仍使用 World 的已有规则。全国地图、全量人物、外交、计略、单挑/舌战和 3D 表现也未完成。下一轮优先接通可保存、可恢复且只结算一次的战术对局，再制作战斗界面。

调试 APK 的签名与旧 CI 包可能不同。存档兼容和覆盖安装签名兼容是两件事；本轮没有配置正式发行密钥，也没有验证真实 ARM 手机性能。
