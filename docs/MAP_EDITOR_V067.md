# 游戏内地图编辑器 v0.67

## 基线与入口

PR #58，分支 `agent/in-game-map-editor-v067`。开始本轮时已将旧 PR #57 合入 main，基线 `83530fbac7d04df9cbeacc293f627ce51fa47bc6`。本 PR 保持待审，不自动合并，也不合并并行武将编辑器/爵位 PR。

开始界面：**地图编辑器 · 自定义地图**。游戏中的 PK 编辑菜单也有入口。编辑器是独立 Activity，从基础地理和指定剧本创建草稿，不复制当前占领状态、不修改正在进行的战局。

## 操作

1. “地形”页先选择地形、画笔范围和工具，再把“浏览”切到绘制。范围是实际六邻接的 1/7/19 格；稀疏触摸点先补齐整条相邻路径。连续画笔、框选、连通填充、吸管各自独立。填充/框选先预览，确认后形成一次撤销事务。双指操作取消尚未提交的一笔。
2. “据点”页选择新增城池/港口/关卡，点选位置、看占地预览，再确认。城市复用正式七格占地，港关为一格。选择实体后可编辑属性、移动、复制和删除；复制分配新 ID。地形保护不会自动搬迁港口或改变边界。
3. 据点“属性 → 剧本状态”设置预览剧本的启用、势力、钱粮兵、气力和耐久。新增据点默认中立和明确资源值，不覆盖历史据点的其他剧本配置。“地区”沿用现有事件地域分类，不是新建任意行政州郡。
4. “检查”运行占地、引用、全部兼容剧本、正式通行及主水系锚点诊断；点击结果定位。独立水域和关卡绕行仅提示，不擅自改图。阻断错误不允许发布，但可保留可解析的待修草稿。
5. 底部“地图 → 保存草稿”可保存进度；离开时自动草稿保存，明确“不保存退出”不会覆盖旧草稿。“检查并保存为自定义地图”发布不可变修订。重命名后再发布会生成新修订，旧存档不受影响。
6. 返回开始界面，选择 **新建游戏 → 全国剧本 → 自定义地图 → 势力 → 开始新局**。原版地图始终可选。自定义城、港、关进入正式列表、占领、寻路、出征、进驻、内政和 AI 所使用的 `World.cities`，不是编辑器图标。
7. “地图 → 导出增量JSON”使用 Android 系统文件保存界面，选定用户可访问的位置；可从文件管理器分享。“导入增量JSON”先读文件、检查指纹和引用，再显示差异；确认才替换草稿，可撤销。相同 ID/修订的冲突需取消或明确作为新地图导入。

## 数据和事务

`MapPatch` 只含地理增量、剧本初始覆盖和明确引用迁移。`CustomMaps` 是编辑预览、新游戏和仓库工具共用的解析入口。基础地理资源未因本 PR 修改；测试实体只在测试地图中。

`MapLibrary` 用 AtomicFile 写入。修订分配先写持久化高水位，再写版本文件，最后启用；删除所有版本仍不复用旧编号。`.bak` 恢复、失败发布、删除后的重新发布均受测试覆盖。撤销历史保存差异，限制为 100 次/8MiB，不为每个单格操作复制全图。

SaveCodec v33 在既有完整世界快照后追加地图身份及港关关联；读取 v31/v32 时迁移为默认地图元信息。旧战局不依赖地图库路径。港关关联城市与实际所有权分开，军团继承仍检查真实势力。自定义开局在地理/引用解析结束后重建战报比较基线，避免把开局编辑误算成战局事件，确保直接推进和读档推进一致。

## 手机 Patch 合回正式资源

需要 Python 3.10+、JDK17。在单独工作分支执行，默认只做 dry-run：

```sh
python3 tools/content/map_patch.py /path/to/phone-map.json --report out/map-merge-report.json
# 审阅打印的逐文件 Git 风格差异，再明确执行：
python3 tools/content/map_patch.py /path/to/phone-map.json --apply
# 写入被中断且存在 .map-patch-transaction 时：
python3 tools/content/map_patch.py --recover
```

工具用正式 Java 解析器检查 Patch，并构建临时资源树。必须能够加载全部九个原有剧本，七个全国开局的地形、据点、资源、开发地、人物/宝物引用指纹必须与手机解析结果一致，才允许写入。输出修改地形行、据点/剧本必要字段、剧本目录 SHA 和地图/发布指纹；保留未改行和注释，不重新排序全图。格式中的顺序索引可能因删除而调整，但稳定实体 ID 不重新编号。

写入有逐文件前置哈希、备份及恢复日志，失败回滚；重复同一文件已成功合入时为校验后的 no-op。工具不提交、不 push。地图代数仍为 native200/revision63，实际地理基线由内容 SHA 识别；不会为了导入而改变地图大小或旧地图 ABI。

## 明确边界

- 自定义地图目前支持七个完整 200×200 全国剧本；两个局部裁区剧本仍使用原版地图，不自动扩图。仓库合并若导致局部剧本加载失败会整体拒绝。
- 删除/禁用被初始设施、营寨或灾害引用的据点会列明对象并阻止操作；本轮没有开发这些对象的完整剧本编辑器。仓库工具也拒绝自动搬迁未适配的初始设施/营寨，不静默级联删除。
- Android 验证是 API29 x86_64 模拟器，不是物理 ARM 真机或全部系统版本矩阵。系统文档导入导出已接入正式代码，但没有宣称测试遍历了各手机厂商的文件选择器/分享应用。
- 回归结果仅覆盖列出的专项；旧全量烟测存在历史地图/移动夹具问题，不宣称所有历史 CI 全绿。性能没有进行 ARM 手机帧率认证。
- 这是地图编辑，不含完整武将/事件编辑、云同步、多用户协作或新美术。
