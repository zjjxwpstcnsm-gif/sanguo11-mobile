用户再次提供的压缩包包含同一份 `MAP_SAN11.jpg`，7200×6752，SHA-256 `a5a4e8c7f9785b6fbadc8487508ff6c937dcef2d782b099f2e876e48d167d4e0`。作者 X GOD / 艾克軋德，2018-05-21；[作者说明](https://xgodgame.blogspot.com/2018/05/11.html)指出绿色线是从小地图放大的行政边界，红格是需要“难所行军”的地块。行政线不当作山脊；没有说明的白灰空带不一概判为道路。本轮保留 v50 全部水域，未重新判明的狭窄空带仍属后续复核范围。

使用 v50 的42城像素锚点，逐区放大判读地形轮廓。100×100移动地图采用2:1缩尺，人工概括山林、谷地和毒泉，并非原版数据逐格导出。

## 逐城对照入口

`data/map/city-review-v051.json`记录42城的原图像素中心、裁图范围、现行坐标及附近港关。本轮涉及13城的周边/连接，其他29城沿用v50状态；有索引不等于逐格验收完成。

```
python3 tools/content/map_reference_atlas.py --index-only
python3 tools/content/map_reference_atlas.py --image /private/MAP_SAN11.jpg --out /private/map-city-atlas-v051
```

第二条在仓库外产生可离线搜索的42城HTML参考图册，保持原图像素，不再次生图、不用OCR。脚本检查源图指纹并拒绝输出至仓库内；原图和裁图不随公开源码或APK分发。图册为原图参考裁片，不是游戏实际截图；安装后的渲染截图由Android探针单独产出。

## 复现、验证和边界

`tools/content/refine_geography_v051.py --apply`仅接受摘要完全匹配的v50输入，确定性写入九份剧本；重复调用先拒绝，不持续叠加补丁。`bash scripts/test-map51.sh --base <v50>`运行近期玩法、原有港关/路线、新增地形与存档测试，并比对非地理记录、区域接缝、资源摘要和精确重放结果。

Android使用 `-e map51 true` 从正式群英剧本加载，检查源图红色难所和毒泉已装包，截取8个地区、全图及横屏，验证镜头操作不改变世界；实际结果和APK源码身份以本轮Actions制品为准。

旧存档保留其内嵌地图，保存格式仍v28；不自动搬动已出征部队或据点。**请新开剧本查看本轮地形。**本轮并未完成全图逐格复刻，浅滩、湿地、细支路和狭窄空带仍有待考定；未测ARM真机和真实手机帧率。
