# v0.31 全图绘制性能

基于已交付 v0.30 本地分支 `6d9452c`（运行代码 `da3f09f`），保留地理、开发地、火系规则、分页和部队拖动。只修改 Android 地图绘制与测试；包名、开发证书和 v21 存档格式沿用。

## 发现和处理

- 旧远景每帧逐格生成地形填充、轮廓和领地路径，全国视角需要访问数万格；新远景为一张已完成的位图加动态对象/标签/选择覆盖层，不在 onDraw 内重建地形。
- 旧版把整张全国的边界 Path 提交给绘图线程，近景也提交全图路径；新版远景边界合入缓存，近景只提交可见格的边界段。
- 三种领地模式同时缓存，切换不创建大图。大图在后台由不可变地形/归属快照生成，任务取消和代际检查防止旧图覆盖新局面；立即提供低分辨率完整图，完成后整体替换，不提供空白过渡帧。
- 最长边 1536、最多 130 万像素，三种完成图加预览图小于 16 MiB。限制纹理尺寸而非创建全国世界坐标大小的巨图。
- 不立即 recycle 已经展示的小地图位图，避免硬件显示列表仍引用旧位图时失效。未曾发布的取消任务位图可以安全释放。
- 远景城池使用势力标记，近景保留建筑图。缓存城市标签与前线判断、复用标签矩形、预计算六角顶点；可建地块移出每帧绘制过程。
- 行动范围、攻击/计略目标、行军路线、拖动、战法预览和战果动画仍实时绘制，不缓存游戏指令或改变执行规则。

## 验证方法

`GameSmokeRunner -e mapPerformance true` 在已安装 APK 的真实 MapView 中运行同一全国场景、相机序列和三种领地模式。每种模式 4 次预热及 24 次采样，记录软件 Canvas onDraw 中位数、P95、最大值和访问格数；这些数值不能当作屏幕 FPS。

优化版还验证缓存重用、内存上限、占城后配色更新、快速更换局面、触摸缩放/拖动、横竖屏、游戏存档不变，以及缩放层级切换时的系统合成器画面。既有 v0.30 触控回归验证建造、恢复、分页和部队拖动没有回退。

具体测量、安装包身份和限制见 [验收记录](validation/v031/README.md)。没有接入用户 ARM 真机，不能承诺所有设备固定 60/120 FPS，也没有证据将用户每一次闪白都归为同一原因。

参考：[Android 硬件绘制与显示列表](https://developer.android.com/develop/ui/views/graphics/hardware-accel)、[Bitmap 内存管理](https://developer.android.com/topic/performance/graphics/manage-memory)。
