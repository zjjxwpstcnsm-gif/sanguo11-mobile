# v0.42 历史特性整合

## 回退原因

v41 运行提交 `7f6a7e6` 基于 PR #40 的 `e6d9868`，该主线实际应用版本是 v0.34。独立交付的 v35–v40 并未同步到该主线；PR #40 不能代表 APK v40，因而漏掉了后续地图、美术和玩法。

原 v40 APK SHA-256：`a3945a0a8d6d3c0ac1c4606d2ecab28b67df9067c0da96e39ca8b44a1f8e8b0e`。地图和图集按原字节恢复，后续玩法依据交付包重建为正式 Java 源码；没有把预编译 DEX 当作源码依赖。

## 整合内容

- 九份正式剧本和目录：100×100 全国地形，42 城、10 关、35 港，开发地、沼泽、浅滩、堤坝、山径及栈道。
- 五份扩展图集：地形、兵种/城关港、器物/内政设施、军事设施、武将头像。恢复等距模型、32 位头像、近远景同源纹理和有界远景缓存。
- 六向连续道路叠加山地底纹，保留 v41 首屏开发入口、攻城与水陆战斗平衡。
- 人员按相邻城市计算行程，支持跨城登用与外交使节实际往返、到达执行、礼金结算；军队及运输仍按地图路线移动。
- 港口和关卡可驻军/出征，禁止城市专属征兵生产；关隘阻挡绕行；失去最后一座城触发势力灭亡并清理港关、军队和任务。
- 武将独立属性列排序、搜索和详情，势力/城市表格；登用、建设、调动、运输和外交主要流程先选目标后选执行人；出征统一在可编辑总览确认。
- 特技详细说明、丰富势力色、任务列表显示出使状态；下一旬显示势力/阶段进度并保留地图与收起操作。
- 堤坝破坏洪水、沼泽战斗修正，以及地形变化后的缓存刷新。

不把本轮整合等同于原版《三国志11》全部规则的精确复刻。

## 开发与打包约定

用户明确当前为开发阶段，使用新开局，不以旧存档兼容约束本轮实现。新写入格式为 v24，以保存实际的登用和使节任务；已有历史解码器未在本轮额外扩展或承诺验收。

统一版本 `versionCode=42`、`versionName=0.42.0`。`tools/content/map-v040-manifest.json` 固定 17 份资源摘要，Android preBuild 执行 `scripts/verify-map-release.py`，旧 v34 地形生成器不再允许覆盖恢复后的地图。后续有意修改地图时应同步更新清单。

最终按用户要求直接构建 APK 并推送 main，停止追加测试；已完成与未完成项如实记录在交付说明。
