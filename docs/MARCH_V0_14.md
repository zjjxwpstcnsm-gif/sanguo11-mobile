# v0.14 点选行军与移动端界面

基于 main `36072094fb983b86b6ef82466712b9f00472c931`。本轮新增可玩的远程目标行军与触控流程，不代表原版全系统100%还原。

## 实际操作

- 出征后保持部队选中。点地图空地或远处城池/部队/军事设施，显示完整路线和固定底栏。青色实线为本旬可走段，金色虚线为后续路段。
- 「开始行军」才改变局面；「取消」、返回键与预览期间旋转不会派出指令。可在预览中继续点地图换目标。
- 下令时走完本旬预算允许的部分；下一旬在其他势力行动、结算和我方预算重置之后继续。移动保留攻击、战法、计略等行动资格。
- 已行动的部队可以预约下旬路线。部队目标按ID跟随，城池归属变化/目标消失时暂停，需重新选目标；堵路或异常恢复后自动重新寻路。
- 城池、部队和军事设施是“接近”目标，走到空闲邻接格停止。不会自动宣战、攻城、攻击、入城或消耗战法气力。抵达后点目标继续已有命令。
- 地块目标精确到格。火场、山地、占用格不能穿过；水陆转换、森林耗费、难所技巧、栈道损失共用现有内核。每一条路段须能在该位置的一个完整旬预算内通过。
- 再点远处目标可改道；固定底栏「停止行军」取消后续计划，已经花费的移动力不返还。手动战术移动替换行军计划；其他手动行动耗尽本旬行动后，未停止的计划下旬继续。
- 「任务 → 行军」显示目标与暂停原因，支持定位和停止。结算摘要显示行军进展，结算后继续保持选中的部队。

## 界面

深色蓝灰底、青绿色重点、圆角与触控涟漪、明确选中态、部队数据卡和气力条。部队底栏独立于右侧滚动面板；预览时展开地图，确认/取消按钮始终可见。保留原有地图手势、城市/武将/任务导航和指令入口。

## 存档与实现

写v13，读取v1—v12并以空行军计划迁移。v12夹具由实际v0.13代码的SaveCodec产生（`estates-drill`），包含原有关系/宝物状态。行军目标、类型、对象ID、下令时归属与暂停原因保存在单位状态中。路径按当前局面重算，避免存档固定过期路线。所有确认预览携带局面快照，过期提交不改变局面。

`MarchOrders`负责完整加权路线和跨旬计划；实际移动通过`UnitOrders`执行，同享冻结的移动预算和野战工程过路效果。相机渲染不执行游戏命令。

## 核验与边界

这是工程实现的触控行军辅助功能，未宣称与原版自动命令时序和AI完全等价。预计旬数假定目标、路况与部队状态不再改变；没有增加原版伤害、移动公式的核验声明。原版全国逐格地图、官方全开局、全特技交互、完整PK、事件、精确数值仍有明确缺口，见[完整覆盖表](FEATURES.md)。单挑/舌战界面和人物模型精细建模不在本轮范围。

新增内核回归覆盖加权绕路、跨旬预算、重复确认拒绝、改变目标、堵路与恢复、异常与恢复、水陆转换、无法跨越的高耗费路段、单位ID跟踪、目标消失、城池易主、到达后不自动攻击、真实v12迁移及存档确定性。Android操作测试增加地图点目标、预览取消/旋转、确认、结算、任务定位、改道/停止、抵达后攻城，沿用三种横屏尺寸与实际旧APK覆盖升级门禁。
