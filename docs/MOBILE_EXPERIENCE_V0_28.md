## 正式入口与权威状态

- 点选部队 → 攻击/战法 → 地图目标 → 预览 → 执行；普通点选敌军只查看。行军继续沿用真实 MarchOrders 预览和随机数不变的取消。
- 低粮、敌我、运输等标记是世界状态的只读显示；领地色降低透明度；同格候选选择保存ID，旋转/重建恢复不会下达命令。
- 底栏‹/›切换待行动部队；空队列解释排除范围。已行动仍可安排下旬行军，也可停止已有路线、查看货物。
- 出征和运输复用数量控件；精确输入、上下限、键盘完成、兵粮留守、续航与容量提示；高阶运输货物折叠，当前走舸与船货分开。
- 确认共享局面快照和一次提交保护；旧局面/旧Activity拒绝执行。各核心正式执行器仍最终校验，不把UI草稿当资源。
- 下一旬继续执行完整模拟；结果为可展开提示，当前待处理用实时ID定位，历史文字结果保留。自动保存继续AtomicFile，失败不报成功。

## 操作路径对照

以下计数从城池概览、地图或已定位的城池开始，计算按钮点击，不包含滚动和向导里原有的选将/数量步骤。配套实装回归保留旧入口，同时验证新入口。

| 目标 | v0.27路径 | v0.28路径 | 变化 |
|---|---|---|---|
| 打开编队 | 军事 → 出征，2次 | 概览 → 出征，1次 | 少切一次分类 |
| 打开运输 | 调动 → 资源运输，2次 | 概览 → 运输，1次 | 少切一次分类 |
| 选择建设 | 内政 → 设施开发，2次 | 概览 → 建设，1次 | 少切一次分类 |
| 全国视角 | 视图 → 全图，2次 | 顶栏全图，1次 | 留出直接找城入口 |
| 从定位结果返回全国列表 | 视图 → 全国城池总览，2次 | 返回全国列表，1次 | 继续原筛选、排序和滚动 |
| 从队1切到可行动队3，中间队2已行动 | 下一部队两次 | 底栏下一待行动一次 | 跳过不能手动行动队 |
| 查看邻接敌军 | 普通点击即攻击预览 | 普通点击显示信息 | 攻击增加明确命令步骤，减少查看时误触 |
| 结束一旬继续看地图 | 确认后必须关闭摘要 | 完成提示留在地图，可点开摘要 | 不再强制关闭结果弹窗 |

竖屏默认详情从地图主体的50%改为38%，地图对应由50%增至62%；这不是整屏面积，固定栏和战果栏另占空间。横屏默认侧栏最大344dp改为312dp。字号、控件高度和标签边界按dp/sp计算；1080像素不是布局常量。
