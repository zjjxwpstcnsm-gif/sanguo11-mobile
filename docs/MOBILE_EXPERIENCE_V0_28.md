## 正式入口与权威状态

- 点选部队 → 攻击/战法 → 地图目标 → 预览 → 执行；普通点选敌军只查看。行军继续沿用真实 MarchOrders 预览和随机数不变的取消。
- 低粮、敌我、运输等标记是世界状态的只读显示；领地色降低透明度；同格候选选择保存ID，旋转/重建恢复不会下达命令。
- 底栏‹/›切换待行动部队；空队列解释排除范围。已行动仍可安排下旬行军，也可停止已有路线、查看货物。
- 出征和运输复用数量控件；精确输入、上下限、键盘完成、兵粮留守、续航与容量提示；高阶运输货物折叠，当前走舸与船货分开。
- 确认共享局面快照和一次提交保护；旧局面/旧Activity拒绝执行。各核心正式执行器仍最终校验，不把UI草稿当资源。
- 下一旬继续执行完整模拟；结果为可展开提示，当前待处理用实时ID定位，历史文字结果保留。自动保存继续AtomicFile，失败不报成功。
