# v0.19 地图优先与横竖屏

基线：main `5aaf57afcbba991d7f9138efd56aa460a022a587`，版本 0.19.0-map-portrait-dev / versionCode 19。

## 改动与操作

- 新游戏和普通启动默认收起详情。顶部只保留两行军情与「视图」；底部保留「功能」、选中对象指令、「下一旬」。移除常驻战报行、地图说明条和非预览状态的部队底栏。
- 「功能」按需打开地图、城市、武将、任务、菜单；「视图」打开全图、定位、导航图、屏幕方向、战报和操作说明。所有旧入口仍可到达。
- 点击城池、部队或设施展开操作面板。普通空地选择收起面板；选中己方部队时点地图目标仍按原行军/攻击逻辑处理。
- 竖屏面板位于地图下方，横屏位于右侧；「展开 / 缩小」调整阅读空间，「收起」或返回键回到地图。面板关闭时地图占满中间游戏区域。
- 屏幕方向可选「跟随系统 / 竖屏 / 横屏」，选择写入应用偏好，重启仍生效。「跟随系统」尊重设备方向锁定。
- 路线预览期间才展示确认栏。竖屏使用两行布局，取消和开始行军均保持可触达；停止行军、下一部队移到部队面板顶部。转屏不执行路线，不消耗游戏资源。
- 地图在面板开合、转屏时保持实际缩放比例和可行范围内的世界中心；新增绝对比例恢复，继续兼容旧比例存储。城池和部队选择保留在底部，可再次打开指令。
- 继承或单挑/舌战待处理时仍展示必需面板并阻止下旬，防止收纳功能隐藏必需流程。

本轮只改变客户端呈现与导航，不修改规则、武将、地图内容和存档 v15，不涉及人物模型细化，也不新增玩法还原完成度声明。
