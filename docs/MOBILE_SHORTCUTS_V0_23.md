# v0.23 移动快捷操作与群英沙盘

基于合并PR #30后的 `d321e9e`，保留其取消选中、行动范围与设施攻防。

## 实際操作

- 内政：选择设施和武将后，在地图高亮地块点选，确认开工。市场、农场、兵舍、锻冶所、厩舍直接Lv3；其他单级设施为其最高Lv1。施工与原费用保留，完成前没有收益。玩家和AI共用规则。取消、退出选址、点无效地块不扣资源。
- 出征：普通编队和快速单将出征均使用兵/粮/金滑块，可精确输入任意整数，也可选一半/最大。兵力受库存、粮食、兵装和统兵上限约束；器械按一件扣除，舰船另验库存。携金最多10000；携粮至少等于兵力。确认前展示留城库存，非法输入禁用确认。成功后自动选中部队。
- 战法/计略/齐攻：选择招式后回地图，高亮内核允许的目标，点选后确认；返回可继续换目标，取消选取退出。内政与野战设施使用同一流程，火球方向也在地图点选。地图选取时暂停下一旬入口，最终执行仍由内核校验。
- 地形：平地草纹、森林树冠、山峰明暗面、水面波纹、山路、浅滩沙洲、木板栈道、毒泉池分别绘制；缓存24个纹理变体。缩远使用各自底色以减轻绘制负担。视图→兵种与建筑图例→地形与通行可查看限制。

42城姓名和相对坐标取已有固定资料表；生成器缩放后构造原创地形和连通道路，城市附近保留出口与建设平地。城防取资料值，资源、归属、道路、水系及人员分配是自制配置。没有把45个存疑关港坐标导入地图。生成器可离线重建并用 `--check` 校验资源哈希。

## 存档与边界

继续写v18、读取v1—v17。新建等级会按现有字段保存；不改写旧存档的设施等级，也保留旧合并任务的完成/取消逻辑，但客户端不再提供发起合并的入口。设备重建会安全取消尚未确认的地图选址/数量表单，不执行未确认命令；普通横竖屏切换保留当前选择。

最高级直建是用户指定的移动版简化规则，不作为原版PK升级规则还原。官方逐格地图和官方完整剧本尚未取得；全事件、全部特技组合和精确公式仍未完全核验，不能声明100%还原。头像仍为16位原创名将插画与稳定默认头像，没有将670名角色误称为670张专属画像。
