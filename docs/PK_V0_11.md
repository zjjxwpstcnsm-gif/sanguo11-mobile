# v0.11 PK研究与培养

基线：main `9c31237bd8b5ea762e54824e0a3c426789f88dd9`（PR #11已合并，检查时无开放PR）。目标仍为Windows PC《三国志11＋威力加强版》。**本轮不是100%还原；不能按名称数量计算完成率。**

## 已进入实际局面的增量

- 四方向能力表：48个普通研究节点，显式前置与跨方向AND条件；50个隐藏候选变体，每势力固定选择10处中的5处，各处一个候选。新游戏使用独立种子，存档直接保存选择，不在浏览、取消或读档时抽取。
- 能力研究每势力同时一项，消耗300金和20行动力，不占武将，按节点跨9/12/15/18旬完成。可在安卓查看前置、进度、剩余次数并中止。
- 培养分基础能力、兵种适性、特技，每势力每类同时一人，消耗20行动力、占用本人3旬。基础能力+5并按低/中/高限制到70/80/95；普通培养次数5/5/3。适性只允许C→B和B→A，各节点5次。原型的无限+3与直接升S新任务入口已关闭。
- 记录武将每项属性通过本系统实际增长的数值，达到20后禁止继续；处理69→70这类截断，以及累计19后最后一次提高到24的情况。次数属于势力节点，所有武将共享。
- 特技培养会覆盖真实`skillId`，确认界面显示旧、新特技；未确认、取消、重复命令不扣次数。完成只扣一次。未完成中止保留次数；行动力与研究金不退。研究与培养均在据点失守或武将归属变化后中止。
- 未具备运行时用途的研究特技禁止培养，界面明确显示不可培养；仍可研究以解锁后续节点。当前阻止：筑城、铁壁、威压、论客、掎角、遁走、鬼门、风水、祈愿、屯田。其他节点有钩子也可能仅部分实现，不能宣称原版完整效果。
- 真实命令加入白马骑射、辅佐支援（仅主将，已行动者仍可支援，不递归）、猛者位移战法负伤与护卫/强运保护，以及强行/长驱/操舵的原型尺度移动加成。负伤写入原有伤病状态并恢复。
- 校正戟兵锻炼为攻击加成、矢盾为30%间接普攻防御、神火计为火计范围3格、熟练兵为气力上限120。训练、出征、气力恢复、战斗与保存贯通120气力；旧战术模块仅用于伤害投影，不改真实部队气力。
- 金按月、粮按季结算，加入富豪、米道、征税、征收。征税每旬发放月基准的一半，富豪仅月初叠加；征收每月发放季基准的一半，米道仅季初叠加。同类特技不重复叠加。界面显示基准与下旬收入。
- 电脑可研究能力并培养空闲武将；不覆盖已有特技。无武将的势力不凭空进行研究。
