# v0.46 · 墨玉界面与连续交互

基线：main `e9600d4351f873ef03bffdf4217fb553d0ec275e`（v0.45），源码归档的 Git tree 与远端完全一致。版本码46，存档格式与签名不变。本轮不修改全国地图、图集或玩法规则。

## 正式功能

- 主地图改为稳定尺寸的 FrameLayout；竖屏底部和横屏右侧浮层不再反复缩放地图，选部队后的指令栏也改为地图内浮层。镜头定位留出被面板遮挡的区域。
- 深墨底色、玉青主操作、立体圆角面板、统一紧凑原生按钮、按压反馈与短距离过渡。城池/部队概览使用数字仪表条，城市指令采用单行分组标签。
- 地图单击在抬手时响应，取消等待双击判定；双击仅用于非战术点选状态的视野操作，不再次派发命令。拖动增加有边界的惯性；定位/全图平滑过渡，触摸即可打断。遵循系统关闭动画设置，空闲无动画循环。
- 地图按世界身份、commandRevision、turn、player、terrainRevision 缓存场景。只改变面板或命令模式时不再重建全国索引/城市威胁；选将变化才重算其可行动范围。正式命令成功时显式使缓存失效。
- 城池/部队快捷条复用控件与滚动位置，面板开关不再清空。城池表、武将表仍使用原生 ListView 回收行；武将姓名与六项能力一屏独立排序，归属/特技、任务状态切换列组，信息没有删除。搜索索引复用，100ms合并输入，提供一键清空。

## 验证与范围

本地 UI projection/camera 51,837项及 terrain connections 451项检查通过。Android 编译、APK资源摘要、固定签名与安装验证以本次 Actions 产物中的日志为准，不把本地纯Java检查当作Android编译。

安装专项 `-e polish46 true` 验证全国地图两种方向的浮层几何、连续刷新缓存、列表搜索/列组、即时单击、动画中断与世界状态无修改，保存六张实际APK截图。完整历史回归与 ARM 真机刷新率/温升未覆盖，不宣称所有设备锁定60/120fps或100%玩法还原。性能变化来自取消重复工作；不使用模拟器离屏耗时伪装真机帧率。
