# v0.47.0 · 港口寻路、破城战损与视野行动演示

基线 main `598b30684395c3e898d15e01b274aec87571a00b`（v0.46.0）。不替换地图、图集、武将头像或已有连续任务系统。版本仍由 version.properties 唯一确定，保存格式保持 v27。

## 规则修复

Army.transitionPort 成为上下河两方向共享的边校验。港口本格仍被据点占用，使用触及同一己方港口的相邻岸线边；不能借相邻普通城市进驻、运输卸货绕过登陆限制。规划、执行、退却、运输和连续目标任务使用同一规则。港口易主后下一次重新规划立即生效，盟军/敌方港口不自动提供己方上下河许可。

AI 路线先严格绕过友军占格，仅在没有可用绕路时保留等待队列的候选路线并尝试让路。到达位置根据该位置真实水陆兵装的普通攻击/战法合法性确定，不再只按出发点射程圈判断到达。边耗费不能超过该模式可支付的移动预算。对不可直接抵达的指定内陆目标，必要的敌方港口可作为中间攻略目标，夺港后重新选择原目标；同时修正相邻隔岸城市使退却部队误以为已经到达的情况。不能移动的单位不会被传送、恢复额外行动力或取消港口限制。

只有实际战斗攻陷 CITY 才触发设施战乱损毁。已建成设施按 ID 稳定排序，各独立 **25%** 概率损毁，使用存档已有确定性随机数；这是本项目平衡参数，并非已经核实的原版精确概率。沿用攻陷时取消未完工项目的既有处理，完成设施通过 Domestic.damage 共用摧毁路径释放地块、清理关联和影响生产产能。正常易主/登用/非城市据点不新增此随机损毁。战报列明损毁数量和名称。

## 回合呈现

TurnJournal 在真实命令成功和全局阶段边界记录动态地图实体差量。移动保留 UnitOrders 执行过的逐格路径；普通攻击、攻城、战法和计谋记录显式类型、目标、损失/异常状态/设施消失和原始结果文字，而不是从翻译日志推测指令。计谋被识破及战法未命中也有动作记录。

TurnWork 仍在后台线程对独立 World 计算一次。演示使用另一份只读用途的地图 World 和已确定的差量：不重跑命令，不消耗随机数，不重复付款或伤害，不把展示中的临时状态作为游戏存档。计算结束、开始演示前保存最终权威状态；暂停、旋转和后台保存亦选择最终状态。进程被系统结束后恢复已结算局面，不重新抽取该回合战斗结果。

当前相机可见区域内播放沿路径移动、出手/投射连线、受击闪烁与数字、计谋脉冲/状态、进驻及破城损毁反馈。屏外行动无动画等待，差量分帧应用；不会强制拖走玩家镜头。仍可平移、缩放、操作小地图和收起面板，不能在演示期间重复下一旬或发出游戏命令。顶部进度条和底部“演示控制”提供暂停/继续、1×/2×/4×及跳过。末尾的旬报告附视野内行动文字记录（最多约 20,000 字）。

表现层当前为现有地图模型的插值、投射线和叠加特效，不是完整骨骼动作或 3D 动画。全局阶段内的守备/火场等批量变化按阶段展示差量；本轮未细拆全部环境伤害为独立施法镜头。可视范围指当前地图视口，不是新增战争迷雾。演示及光效遵循系统减少动画设置。
