# 玩法研究与证据

研究日期：2026-09-13。状态：已建立系统范围；未完成所有数值、隐藏机制、角色和地图的逐项核对，未进行原版实机对照。不能据此声称「完全掌握」。

## 版本基线

暂以 PC《三国志11＋威力加强版》为目标，保留本体/PK规则差异。正式冻结前记录地区、语言、补丁版本、原版版本号和文件校验值。PS2/Wii的新增剧本、达成事件、水浒武将等单列，不直接混入 PC 范围。未纳入用户没有要求的玩家 MOD。

PC 官方商品页明确介绍内政开发、计略陷阱战斗、3D单挑，并列出PK的剧本事件、决战模式、设施合并、研究及武将/据点编辑。[S1]

## 核心玩法理解

1. 统治势力，使用有限的武将行动与资源，在同一张战略地图上进行经营和战争。开发设施直接影响后勤，破坏设施会影响城市经营；不是进入另一张独立战斗棋盘。[S2]
2. 城市经营必须与出征相联：钱粮、士兵、兵装、部队携粮、人员在城/出征状态共同约束扩张。M0只实现这种约束关系的最小样例，原版消耗和结算时点尚待核对。
3. 兵装、武将适性、特技、地形和部队编组决定战术选择。战法能造成位移，可与设施、陷阱配合；原版暴击、连锁和成功率必须通过对照用例核验。[S3]
4. 技巧通过势力行动积累的点数推进。官网示例说明技巧分系统和等级，但该页为主机版，PC各分支应另核对，不能直接把其数量写死。[S4]
5. 单挑包含方针、斗志、必杀及队友替换机制，不能用一次武力比较替代。[S5]
6. 舌战包含话题牌、话术、愤怒和性格相关效果，不能用一次智力比较替代。[S6]
7. PK内政合并必须处理相邻条件、可吸收设施等级和格位变化；能力研究与势力技巧是不同系统。[S7][S8]
