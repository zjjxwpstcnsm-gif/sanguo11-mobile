# v0.44.0 · 沙地、黄河与主界面控件

基线 main `7f135f334eb185819b6d2115fa1b97eaf759286b`（v0.43.0）。不重新运行旧全国地图生成器，不回退立体地形、头像、势力色兵种图集或设施次数规则。

## 正式规则与显示

追加 `World.Terrain.SAND`（原枚举序号不变），剧本字符 `A`，存档格式 v26。枪兵自身位于沙地时，突刺、螺旋突刺、二段突刺统一被 `War.tacticError` 拒绝；玩家、战法预览、AI 共用，失败不消耗气力和行动。普通攻击、普通陆路通行不受此限制；目标在沙地而枪兵在平原仍可施法，戟兵等不被误禁。

沙地使用缓存沙纹与暖沙色；近景、远景与导航图识别同一地形。空地详情、图例均显示规则，避免仅换贴图。新存档包含沙地可正常保存、读取。

## 修订地图快照

全国地图共517格沙地：西北495、邺城黄河岸14、庐江周边8。沿既有黄河主河道新增151格水面，保留港口、关卡、城池及开发地；许昌、新野平原与通往宛、陈留、汝南等地的陆路清理45格阻路山地，洛阳关隘周边山壁不改。

九份已打包剧本同步修订；区域图按原裁切偏移使用同一全国改动。城市、港关、开发地及开局部队坐标不变。详细数量、偏移、六条陆路见 `validation/v044/geography.json`。

`tools/content/refine_geography_v044.py --apply` 是对指定v43快照的一次性、带摘要检查的地理修订工具；只接受原基线，重复运行拒绝二次扩宽。新版本采用 `map-release-manifest.json`，旧 `map-v040-manifest.json` 保留历史证据，18项地图/图集资源继续在APK构建前校验。

**地图变化需要新开局。旧存档保留原地图，不强行覆盖已建设施与在途部队。**

## 手机操作

主界面顶栏新增“势力”快捷开关；点击立即开关着色，不移动镜头、不关闭当前面板；长按选择势力/据点辖区。与视图菜单双向同步、持久保存，AI结算期间仍可切换。

公共控件统一细边框、8dp圆角、选中/禁用/聚焦/点击反馈。主栏和操作栏统一48dp高度，按钮视觉面收紧到36dp，保留常规触控区域；运输副将、军团设置等原生按钮也使用同一外观。
