# v0.25 战略AI、军团经营与全国管理

基线：核查 main `a76ed8b`、唯一开放 PR #32、无冲突及 CI35061932367 三屏成功后，按授权将 #32 合并为 `7f1408c86a65faf113e79f66e4447e2aec6b270c`。本轮分支 `agent/strategic-ai-management-v025`。开发包名和签名保持不变。

## 已有功能与本次变化

v0.24 已有真实命令、独立军团预算、城市轮换、领地三模式、远射接敌、基本生产与指定运输。本轮没有将这些列为新功能。

- 原先每旬重新选择城池，没有持续任务。本轮增加可存读的目标、出发城、集结/防守状态与无进展计数。目标评分使用共享多目标实际路径、守军、城防、附近援军、友军任务和携粮续航，原目标有稳定性加权。
- 实际出征部队先腾开出口并在共同后方据点集结，兵力足够后协同推进；不足时等待增援，连续六旬无进展或粮食不足即尝试归城。器械缺少护军时先用真实命令派出护军。城受威胁时保留动态守军并可出城拦截，防守任务超出九格或威胁消失后归城。近战会腾出邻接攻城位，并结束本次行动以免立即走回挡路。
- 原军团没有调将。本轮按驻将和在途人数，将富余城市的人才实际调往同军团不足三名驻将的城市；按政治、魅力与距离选择。源城至少留三名驻将，运输至少保留两名。没有瞬移和新增武将。
- 自动运输扣除在途物资后计算金粮兵和兵装缺口，并受目的地容量、出发城保留量及100金运输费用约束。未指定目标时仅在本团内支援受威胁/缺粮城；明确指定运输目的地时优先满足该目的地的容量允许调拨，尊重玩家明确方针。电脑后方也用同一物流逻辑支援缺兵前线。
- 军团新增可保存的留守兵力、外运保留金粮、自动调将和补给运输权限。保留量约束外运/出征/部队补给；巡察、建设等城务仍正常支付费用，不能让默认5000金的城永远无法经营。禁止生产下所有生产命令拒绝；禁止调将和运输也在实际命令入口检查。
- 军团已有禁攻与城市/势力攻略限制继续有效，并补上对非指定城市内政设施的袭击限制。改编清除旧进攻意图；已知出发城移出军团的部队回第一军团。已支付并出发的调将和运输继续履约，解散军团不吞货也不退款重发；失城时沿用真实在途改道、容量等待与运输截击规则。
- 内政发展对照城内真实粮耗与季粮收入安排农场，计入在建农场，避免把全部槽位填成市场；断粮时优先调用实际商人交易，正常扣金、消耗行动力并遵守每旬限额。全国续航复用城内粮耗，港关屯田免粮耗不会误报缺粮。
- 本轮经营报告记录实际成功指令、调将、运输失败原因及预算/资源/缺将/治安阻塞。报告、任务意图和设置进入存档。

## 手机入口

- `视图 → 全国城池总览` 或 `功能 → 城市`：状态筛选（接壤、敌军逼近、缺粮、缺将、治安、托管受阻）、军团筛选、兵力/续航/闲将/治安等排序，原生滚动列表点选定位。
- 城市页面 `筛选 → 批量划入军团`：逐城列出可执行项和原因，再确认统一编制；君主驻地与其他军团成员不会被暗中挪走。取消不改变局面。
- `视图 → 军团托管 → 军团`：最近经营报告、实际在途货物、部队攻略目标；`经营设置`编辑留存与调将/补给权限。军团方针、禁攻、禁产和指定目标仍从`重编`设置。
- `视图 → 领地着色 / 前线`保留关闭、势力合并、据点辖区。橙圈标示敌境接壤，红色“!”标示已有敌军逼近。筛选、排序和列表位置随Activity重建恢复。

## 存档与规则依据

写 v19，读 v1—v18及已有两种v13。新增内容在v18扩展后追加；真实v18夹具由修改编码器之前的v0.24代码生成。旧军团默认留守10000兵、保留5000金/40000粮，允许自动调将和补给；旧部队没有伪造的进行中任务。读取验证范围、引用、重复编号和报告长度。

原版结构依据沿用仓库已经核验的[官方PC说明书](https://cdn.akamai.steamstatic.com/steam/apps/628070/manuals/32sangokushi11wpk_manual.pdf)，军团方针正文37页及PK指定运输19页；既有核验与PDF指纹见 `WORLD_V0_14.md`、`CONTENT_AI_V0_18.md`。本轮修复“都市攻略时仍袭击非指定城的内政设施”这一方针贯穿缺口，继续使用现有行动次数、生产/运输费用及实际兵装规则。此次联网重取PDF失败，未把未重取资料当作新数值核验。

目标评分、守军权重、八格集结半径、九格防守范围、六旬等待、三旬受阻撤回、三名驻将和储备阈值均为工程AI策略；批量编制和可编辑留存是移动版便利功能。不是原版精确AI或原版公式。按附近可见兵力估算威胁，未实现战争迷雾、完整战略博弈或全地图最优调度。
