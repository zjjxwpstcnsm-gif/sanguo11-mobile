# 战略层：设施、人事与后勤

v0.5 人事与治理规则及安装验证见 [集成记录](INTEGRATION_V0_5.md)。以下设施表列出基础增益；最终收入另受治安/太守影响，最终征兵另受兵源/治安/执行武将魅力影响。

本章全部是可运行的**工程近似**，并非原版核验公式。两份地图仍为原创沙盘。

## 设施

| 类型 | 建设金 | 完成后的实际作用 |
|---|---:|---|
| 市场 | 1000 | 每月金收入增加400 |
| 农场 | 800 | 每月粮收入增加2500 |
| 兵舍 | 1200 | 每次征兵增加500 |
| 锻冶所 | 1200 | 每次现有兵装生产增加500 |

每城最多6处，含施工中。位于城池1至2格内空闲平地，不得与城池/设施/战斗部队重叠，也不能堵死任意城池最后一个陆路出口。已建设施阻挡战斗单位移动和战略陆路规划。

每次建设消耗10行动力及一名在城闲将。政治80以上需要2旬，否则3旬。施工期间即使旬行动重置也不能重复派遣。取消不退款，武将当旬已行动；拆除建成设施需要闲将和10行动力，不退款。城破未完工设施取消，原有退却规则处理武将；完成设施留给占领方。没有升级、合并、特殊地块或科技前置。

基础月金800、月粮5000保留；设施加成在每3旬收入结算时计算，再应用治安与太守加成（已包含于 monthlyGold/monthlyFood）。建成当旬若恰逢收入结算则立即生效。兵舍/锻冶所加成先检查容量，不会扣费后截断产出。电脑在军事命令之后使用闲将和剩余资金，每城至多开发一处市场和一处农场。

## 调动与运输

从己方城池选另一座己方城池以及本旬闲将。每次10行动力，运输另收金100。运输数量可独立输入：金0–100000、粮0–200000、兵0–20000、每类兵装0–20000；至少一种货物大于0。确认前校验所有资源，成功后货物一次从出发城市扣除并进入任务，武将离城进入在途状态。不会继续出征或执行内政。

战略任务使用确定性Dijkstra：平地1点、森林2点；每旬4点，水域/山地/敌城/设施不可穿越。路线每旬重新规划，预计旬数按分旬预算计算。起点允许离开刚失守城池。任务是**非战斗战略在途标记**，不占战斗格、不被部队拦截、不战斗、不在途耗粮，不等同原版运输队或水运。

抵达后先检查所有货物是否可完整入库。任一库存超上限，任务、武将和货物全部保留待命，下旬重试，不静默丢弃，不重复入库。目的地失守则选择陆路可达成本最低的己方城池（同成本按城市ID）；无可达己城则原地等待。可在任务详情消耗10行动力改道到其他可达己城，包括返回起点。失去全部城池和作战部队的势力按既有胜负规则覆灭，任务清除，运输携兵不算存活作战部队。

每个全局旬：各电脑行动 → 日期推进 → 建设与在途任务结算 → 部队/城市耗粮 → 月收入 → 玩家行动重置。当前抵达武将可在新的玩家旬行动；这是全局回合的工程约定。
