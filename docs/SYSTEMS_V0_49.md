## 部队攻防与编队

基础攻击=编队武力×兵装攻击系数×适性系数；基础防御=编队统率×兵装防御系数，亦乘适性。整数向下取整；当前面板再计地形。详情可展开每名副将贡献。智力与兵种适性取全队最高。普通副将只贡献比主将高的差值的1/4；亲爱1/2、血缘1/3、夫妻/义兄弟全部差值，厌恶无贡献。两副将分别计算取高，不累计加法；低能力副将不反向扣除主将能力。

兵装/适性系数参照资料表；这些数值也用于真实伤害与预览，不是 UI 虚构数值。当前移动版的基础伤害、地形、科技/精锐、特技、设施、暴击和战法系数仍有工程化差异；条件性伤害修正不一概折算到面板。副将原始实验注明 PS2 版，不能证明所有 PC/PK 内部细节完全相同。

## 忠诚、相性、军师与倒戈

- 相性0–149按环形距离计算，义理1–5。源档原有相性及义理已进入可复现的 `profiles.tsv`，670名武将新开局按资料初始化；未知相性明确显示未录入，不伪造数据。旧档读取保留原局面，未知相性为-1、义理中性3。
- 自然忠诚衰减按日历季初（1/4/7/10月），而非每旬。普通在外武将会受相性与义理影响；君主本人及其在世配偶/义兄弟免除忠诚下降。对君主的亲爱、血缘另保护自然衰减。原有亲民、仁政等效果继续发挥作用。
- 在外普通部队与运输队都不能金钱褒奖；UI 不列出目标，核心仍拦截，失败不扣费用/行动。回城后按原有褒奖入口处理。原版可能允许的野外授予宝物本轮没有额外开放。
- 普通登用综合忠诚、义理、执行者魅力/政治、目标与执行者/新君主相性、亲爱/厌恶及夫妻义兄弟限制。忠诚+义理大于96时普通挖角拒绝。低忠诚不是必然成功，亲密关系有优先限制。俘虏招降也共享相性/义理修正，但保留独立的俘虏基础公式。
- 任命军师原本已支持：据点 → 军政/俘虏/官职 → 任命军师。本轮不是把旧入口冒充新增；新增的是目标优先、执行者列表中的可见军师推荐、相性差及实际成功率排序。推荐不消耗或窥看随机数，不承诺必成；抵达重算当时状态。
- 野外登用以真实部队ID追踪，出使有路程；目标已变阵营、离队或消失时重新校验。主将接受后部队原位换归属，兵数/粮/金/兵装不复制、不清零；副将按关系、忠诚、义理和相性分别判定。拒绝者返回原势力据点，原单位不再引用他们。
- 单独登用副将仅使该副将离队，原主将、兵粮及部队势力不变。主将留在原地指挥倒戈部队，仅使者返程；不把主将错误传送回城。原自动目标/AI订单/军团归属/护送关系停止或清理；运输重新绑定新势力据点等待指令。随军同势力俘虏获释，其余俘虏俘获者同步更新。

精确移动版概率、随从阈值与扣忠数量集中于 `Loyalty` / `Strategy`，为确定性、可存档、可测试的设计参数，不包装为已核实的原版完整公式。特殊夫妻长幼、隐藏忠诚超过100等尚未逐项复刻。

## 粮秣与出征

普通部队旬耗粮=ceil(兵力/10)，运输队=ceil(兵力/20)，零兵力耗粮0。现有阵/砦/城塞范围分别减耗15%/30%/50%，由同一设施服务处理。UI、AI补给判断与真实结算统一调用 `Logistics`。

出征滑块、数字输入每次实际改变兵力都将粮设为兵力两倍，受当前库存及既有携带上限限制，并即时显示基础旬耗和可维持的完整旬数。允许再手动调整粮食；点击已经选中的兵种、同数量刷新和Activity旋转不覆盖手动值。库存不足明确提示，不静默显示虚假的两倍。既有出征校验仍要求携粮不少于兵力（即10旬基础口粮）；本轮未调整这一出征下限。粮够与否还受后续损兵、补给、设施范围变化影响，所以标明估计前提。

结算时不足支付本旬所需粮，则剩余粮归零，现有兵力逃散10%（不足10兵最少1，最多当前兵数）；口粮充足的最后一旬吃到0不会提前逃兵，下一次不足时才触发。重新补足口粮立即停止后续逃兵。最后一个士兵离队后正常移除部队并释放主副将引用。运输队遵循同样不足粮机制。

原版资料明确每旬耗粮1/10与1/20及断粮持续减兵，但没有可靠证明精确逃兵率；10%是本轮移动版平衡参数。现有携粮上限亦不是对原版5万上限的新宣称。
