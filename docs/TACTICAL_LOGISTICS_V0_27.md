## 唯一货物持有者与指令

`Domestic.Mission extends World.Unit`，金/粮/兵/位置/行动/编队直接来自同一个对象。它只保存在`domestic.missions`，不复制进`units`。`fieldUnits()`暴露地图上的运输给战斗、控制区和UI，`unitAt()`统一占格；任务编号保留，战场编号使用10000000以上独立区间。列表和报告均读这份状态。

出发城市库存 → 运输携带 → 实际每旬耗粮、战损、战利品或最终入库。毁灭立即移除任务和战场引用；缴获金粮在获胜部队中，武将逐个进入既有俘虏或逃脱去向。满仓队伍留在城外相邻实际格子，可以被攻击，不把货物提前写入城库。卸货时清零货物；返程只有人员，沿用旧的战略人员旅行模型。

路线与改道共用MarchOrders、UnitOrders和Army地形成本。水陆转换冻结同一旬预算；进入敌控制区结束剩余移动，运输本身不产生攻击控制区。停止清掉实际自动行军指令，保留当前位置和货物、继续耗粮；地图地块多旬行军到达后待命，地图友城命令恢复交付。预览/取消不改局面，快照防旧确认重放。

友军堵塞时，可沿忽略友军占格的几何路线找到排队方向，但每一步仍由真实占格、控制区和当前剩余预算批准；不能穿过友军。相向运输按固定任务编号让行。有侧袋的单格走廊回归验证双方依次抵达；不把这称作任意复杂路网的全局死锁保证。

贵重运输的近程路线有敌而实际护军不足时等待，报告敌兵、护兵及恢复条件。地图显式地块命令允许玩家改变实际路线。AI用已有野战部队移动/攻击护送，不生成资源、护盾或额外预算；守城、器械、低粮或低兵部队不转作护军。敌军仅考虑近距离运输，家城受威胁时限制追击范围。低粮前线可接收同军团的真实邻接运输粮；可达援助将及时抵达附近己城时允许有效等待，否则保留撤退逻辑。未授权委任部队不能自动抽取第一军团运输。

## 手机入口

- 城池 → 调动 → 资源运输：保留三将/返程，增加楼船、斗舰货物输入，确认页显示库存、预计耗粮和目的地容量。
- 地图运输图标“运”：点选查看三将、携兵金粮、已耗粮、兵装/船货、目的地、阻塞和剩余移动；固定指令栏为行军、补给、停止、货物、取消。
- 行军 → 地图目标 → 路线预览；补给 → 相邻友军 → 输入兵粮金 → 预览确认。运输详情可定位目的地和已有护军；野战部队显示护送意图。
- 任务当前位置、全国物流异常与在途援助沿用原入口，并读真实任务状态。预测依赖当前道路、占格与威胁，不保证到达日期。
