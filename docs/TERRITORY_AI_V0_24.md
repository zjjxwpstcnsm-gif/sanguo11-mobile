# v0.24 领地、军团与接敌

基于已合并 v0.23 的 main `a76ed8b`。版本 24 / `0.24.0-territory-ai-dev`，存档仍为 v18，保留 v1—v17 读取兼容和固定开发签名。

## 地图

“视图 → 领地着色 / 前线”提供关闭、势力范围、据点辖区三种模式，偏好保留到重启及转屏。城、关、港都是辖区源点；同势力辖区在势力模式下合并边线，据点模式保留内部边界。半透明颜色保留底层地形，导航图同步显示颜色。

红圈标记辖区与交战势力接壤的据点。“前线据点”按本方优先列出并可直接定位；“势力领地图例”显示颜色、据点数、前线数，城池概览显示辖区格数与邻接据点。占领、劝降和外交变化后按实际归属/敌对关系刷新。同盟、停战、空城不计入敌对前线。

辖区为多源地形加权扩散生成的工程规则，平地/困难地形/水面成本分别 2/3/5，山体阻断、山径连通；相同距离按据点 ID 稳定决胜。无据点可达的孤岛及山体不着色，错行坐标填充区永不占地。它不是取得了原版行政边界，也不改变寻路、建设半径和伤害规则。领地图层覆盖当前加载的可玩地图，包括42城群英沙盘及导入大地图；资料页城市坐标图不等于可玩原版全国地图。

## 托管

既有第二至第八军团真实执行城务和部队命令。新增“视图 → 军团托管”、城池概览/内政的“城池托管 / 军团”，可以快捷新建内政军团、把城并入已有军团、自定义编制；后方批量预选排除君主驻地、既有军团、接壤前线与敌兵接近的据点。编制消耗第一军团20行动力，新团下一旬恢复自身60行动力，再于结束旬时经营。撤销恢复直接管理；前线、无武将及超预算的编组不会凭空获得资源。

军团状态展示驻城闲将、资源、预算及等候原因，战报记录本旬预算消耗。高危城先处理治安和紧急人事，其余城市按旬轮换，避免大军团末尾城市长期挨饿。守备优先处理战备；生产按适性和兵装缺口选择；运输附1000护军、保留至少10000守军和既有金粮底线、避免同目标重复派车，并尊重目的地容量。所有行为继续调用真实命令及预算校验，关闭进攻/生产选项仍生效。缺武将必须实际调入人才。

## 战场AI

修复近战部队在远程计略范围内先出手导致停在原地的问题：枪/戟/骑/剑与远程部队都比较本旬可达攻击位置，按伤害、反击、地形威胁和移动消耗选择走位，再执行合法攻击或计略。位置探针与玩家普通攻击共用规则，不消耗 RNG 或临时挪动真部队。异常状态、行动力、ZOC、森林射击和外交限制仍有效；优先扑火和解控。

撤退必须实际移动或入城才视为成功，避免“存在路径但走不了”直接跳过本旬；远程部队保留拉开距离攻击。AI新增内政设施攻击，能够打击敌方经济设施。它仍为确定性启发式 AI，不宣称达到原版等价或无敌。
