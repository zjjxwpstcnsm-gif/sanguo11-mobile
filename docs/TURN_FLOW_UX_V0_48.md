# v0.48 逐势力行动与直达出征

基线：main `788cb858630f15d781909cd15c3406b07dbb6256`。所有修改接在完整v47源码上，不重做地图或替换图集。

## 结算顺序与耗时

旧TurnWork在工作线程完成nextTurn后一次性交付整个journal。没有sleep或定时补齐百分比；耗时来自SaveCodec复制、AI和规则/事件差分。新World.TurnProgress在委任军团、每个敌方势力、全局设施后勤、己方恢复/持续任务后暴露明确boundary。TurnWork只允许一个完成批次在途，主线程消费不可变事件并确认后，工作线程才计算下一阶段。小地图、拖动和缩放可继续使用；战斗命令保持锁定，不能对部分结果操作。屏幕外事件不做动画等待。计算中的24ms重绘轮询不是引擎限速。

运算耗时从线程开始计时，扣除呈现确认等待，含局面复制、规则运算、验证和摘要；并非真机帧率结论。暂停、倍速、跳过保留在TurnWork中，横竖屏不会取消跳过或重开线程。Activity真正销毁时取消等待中的工作线程，旋转时保留。完整结果才可保存；过程中自动保存旬初权威局面，绝不保存演示world。系统杀进程中断时从最后完整局面恢复，而不是保存半个势力阶段。

## 设施事件与地形

Fieldworks真实命中分别记录FACILITY_ATTACK、FACILITY_COUNTER，来源坐标和势力使用设施本身，不再误用当前active势力。军乐台按EnergyRules实际Change记录RECOVER；+5等上限截断显示实际值，满气不伪造+10，诗想/奏乐保持原优先级。被摧毁/未建成/敌方军乐台不提供恢复；没有改变攻击频率、范围、数值或全局旬结算时点。箭塔与反击显示发射/目标受击，恢复显示绿色脉冲与音符。

森林和湿地由共享规则拒绝新建，不扣金、不耗行动、不消耗RNG；地图候选格和旧city helper也排除。保留火船水域例外、沙地及原本的地形限制。不会强拆旧存档已有设施，也不修改内政开发地规则。

## 出征及小型选项

DeployWizard.start永远新建空草稿；只有旋转恢复和同一编队内选择武将返回才恢复草稿。取消/完成清理整个formDraft。主将、副将、兵种无前次残留；舰船回到默认走舸，数量回到本次库存默认值。兵种9项和舰船3项同屏点选，图标、库存、选中态和缺库存禁用直接显示，切换更新兵力范围和确认校验，不弹二级详情。选武将取消不再静默删除副将，移除有独立按钮。

小型枚举/数值选项（≤12项）复用紧凑图标/按钮栅格，武将等大型列表继续可搜索排序。不是全部菜单重写，也不删除必要的最终执行确认。

## 验证与边界

`scripts/test-turn48.sh`包含原v47六组专项回归及新设施事件、禁建原子性、逐势力顺序和最终存档确定性检查。`Turn48Probe`用于Android实装检查逐阶段阻塞/续播、暂停旋转跳过、实际设施帧、同屏选装、草稿重置和出征执行；运行结果以本轮Actions制品为准，不能将未运行项标为通过。沿用固定开发签名，地图资源通过原字节清单验证。未做ARM真机帧率和全量历史长局回归。
