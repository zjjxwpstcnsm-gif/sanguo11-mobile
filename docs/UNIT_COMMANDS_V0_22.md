# v0.22 部队指令与内政设施攻防

用户报告：地图内政设施不能攻击，选中后空地点击全部转成行军，不能方便取消，战法入口难找，行动范围不明显。

## 实际变更

- 原先 `onTile` 没有内政设施攻击分支，空地/设施一律走自动行军预览。现在内政设施、部队、城池、军事设施按类型与外交关系处理；超出射程先明确询问是否规划靠近。
- 选中部队后固定显示行军、攻击、战法、计略、取消选中；本旬不可执行的攻击/战法/计略禁用并显示原因。行军仍可安排下一旬。
- 普通点空地、再点本队、取消选中按钮解除部队选择；返回键依次退出路线预览、指令模式、选中状态。收起详情仅隐藏详情，固定指令保留。
- 必须先选择行军，空地点击才会出现路线预览；预览仍需开始行军确认。旋转/Activity重建保留模式与预览，不重复下令。
- 青色格来自实际安全行军的剩余移动预算，受地形、火场、占格、ZOC、行动状态影响；红框为有效普通攻击或兵器战法目标。移动后重新计算，攻击/战法结束行动后清除范围。
- 内政设施加入耐久与地图耐久条。普通攻击、兵器/水军可用战法、持续火场均能扣除真实耐久；协定目标受保护。摧毁后立即移除经济加成、释放地块、释放建设武将并清理依赖工房/造船厂的生产任务。
- 自动行军可指定敌方设施作为靠近目标；按设施ID/归属跟踪，摧毁或变更后暂停，不攻击、不占入设施格。
- 存档升级为v18；v1—v17读取保留，旧设施初始化满耐久。真实v17夹具由修改前源码编码，不是新编码器改头伪造。
- 兵器战法复用部队统一权限校验，防止直接指挥委任军团单位。

## 工程参数与未完成项

本轮内政设施耐久统一1000，普通攻击伤害沿用军事设施基础公式 `200 + 部队武力×2` 和已有攻城技巧修正；兵器沿用现有对建筑伤害，火场每旬200。以上均是明确的工程参数，未宣称原版精确数值。设施部分受损时维持产出，直到摧毁；没有新增独立的内政设施修复指令。普通枪/戟/骑兵战法仍主要针对部队，兵器战法已纳入设施；没有伪造全战法对全目标兼容。

全国原版逐格地图、官方完整开局、全部事件/PK/特技交互及精确公式仍有缺口；这一轮不能称为100%还原。
