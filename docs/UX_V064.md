# v0.64 军团、征兵与地图操作

基线：main `315c222cfb098996ed9bfc540d427cea2105522c`。不改地形、港口坐标、城市七格、美术或存档格式。

## 行为

1. 军团只保存城池成员；同势力附属港关跟随所属城池，涵盖权限、都督、自动经营、调将、补给、出征继承、易主和撤销。全国45组所属关系按仓库剧本数据固定，不随当前敌我归属重新分配。自定义地图按全部城池距离、ID稳定回退。港关与所属城池不同势力时保持直属，不能控制敌军。君主在附属港关时，其母城也不能托管。旧存档中的独立港关成员移除；仅含港关的旧军团释放，不擅自托管原本直属的母城。
2. 点部队仅选中，保留行军、进驻、攻击、战法和计略命令；通过详情按钮或底部选中对象入口主动展开。移动、攻击的目标选择不触发目标详情。
3. 征兵后气力为 `floor(旧气力 * 旧驻军 / 新总驻军)`。新兵初始训练气力为0，训练恢复气力；预览和执行共用公式。失败征兵不改变资源、气力或设施次数，战报显示实际变化。
4. 每年1、4、7、10月上旬全球结算一次，每城最多恢复5000兵源，上限20000。按剧本起始月份对齐；港关不恢复；读档或势力切换不额外发放。既有超上限编辑数据不继续增长。界面显示兵源、上限、规则和距下次恢复旬数。这些数值为本项目平衡参数，不宣称原作精确公式。
5. 顶部年月旬独立整行显示，不与势力、剧本名称争用标题宽度，不设置省略；保留行动力常驻。
6. 设施选中覆盖共用实际战斗空间规则：阵2、砦3、城塞4；箭楼1–2、连弩楼1–3、投石台2–3格；军乐和太鼓2格；石兵八阵邻格。投石台保留近身盲区。火球按方向和阻挡，火种为首爆范围，堤坝为相连两格低地。建造中明确标识预览，墙没有虚假范围。切换、取消、摧毁清除范围，升级后刷新。
