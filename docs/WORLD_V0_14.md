# v0.15 行军与天下整合版（含 v0.14 天下系统）

整合 PR #15 点选行军（`b2eec25d20cadf4cd5196aeb0b6e99d9e556191b`）与本轮军团天下增量；基于已合并 PR #14（主线 `36072094fb983b86b6ef82466712b9f00472c931`）。保留 v0.13 的关系、宝物、编辑器、新武将、PK研究、建造及历史存档。**仍未达到 PC《三国志11＋威力加强版》100% 还原。**

## 本轮可玩的内容

- 整合点选地图目标、逐旬行军、路线预览、改道、停止与固定操作栏。路径预算包含ZOC停步，遁走等效果同时影响预览和执行；委任军团部队拒绝手动行军。


- 菜单→军团与天下→军团编制：新设、重编、撤销军团，选择多个己方据点、自动选都督、自主/内政/守备/都市攻略/势力攻略方针、进攻与兵装生产权限、指定运输据点。
- 新军团下一旬得到独立的60行动力。自动城务、建设、生产、出征、移动、攻击和运输均调用现有真实命令；第一军团行动力与军团预算分开。每团每旬只运行一次，撤销不返还其预算。运输实际出城、跨旬前进并受截击/改道/容量规则约束。
- 都督按统兵上限、统率、武力、功绩和ID自动选取。军团军队攻占据点后归入本团；目标已占领或签订协定时改为守备；所属城池失守、部队消灭、都督出征/被俘、第一军团丢失全部据点均有清理与接替逻辑。
- 同讨、妖术、落雷加入部队计略；齐攻加入部队命令。落雷会伤及自己的相邻部队及设施，生成可保存火场；协定势力受保护。百出减气力、计略免疫、特技持有人的能力比较进入实际结算。相关特技也影响电脑选招。
- 敌部队及已完成军事设施的邻接格形成阻挡区域（ZOC），进入消耗剩余移动力，仍可攻击。遁走/飞将仅适用陆上非兵器，推进仅适用水上；运输队也检查阻挡。毒泉为新增地形，行军与驻留减兵，解毒免疫。移动预览和执行使用同一规则。
- 蝗灾、疫病有持续时间、资源/治安损失及设施损毁或伤病；风水仅预防新灾。七月丰收实际增加粮草，祈愿提高发生率。每月检查贼患，低治安可能产生持久营寨；可在地图上选择部队讨伐。营寨按旬反击附近部队、按月劫掠城市及破坏设施，摧毁后停止活动。
- 亲乌/亲羌/亲越/亲蛮防止配置区域对应异族营寨，不防普通贼寨；威压降低安全治安门槛。区域必须由剧本明确配置，不根据虚构地名猜测。
- 论客在同盟/停战提议被拒绝后，与可出面的对方代表进行真实舌战。胜利才成立协定，失败/认输不返还出使费用；代表不会被当作登用对象。舌战进行中可保存、恢复并继续出牌。
- 新增“军团与天下”原创演练，包含5据点、19将、6部队、毒泉、初始蝗灾、可讨伐贼寨和已明确配置的四种边境区域。其他旧沙盘与旧存档默认不自动新增随机事件，可在菜单开启；已有灾害和贼寨不因关闭新事件而消失。

|特技|实际命令/规则|主要验证|
|---|---|---|
|遁走、推进|陆水ZOC通行及运输行进|有效地形、兵器排除、协定、预览与执行|
|解毒|毒泉行军/驻留/运输兵损|真实兵力变化与免疫|
|掎角、铁壁|齐攻触发混乱；齐攻转普攻|参与者行动锁、概率、其他参与者保留行动|
|诡计|同讨成功率|持有者智力比较、邻接同势力目标、双方损兵|
|妖术、鬼门|解锁妖术/落雷|范围效果、费用、免疫、友伤、保存火场|
|论客|外交舌战|出牌、胜败协定、一次结算、中途存读|
|亲乌、亲羌、亲越、亲蛮|对应区域异族营寨|不影响普通盗贼、持久营寨与讨伐|
|威压|贼患治安门槛|实际发生检查条件|
|风水、祈愿|灾害预防、丰收概率|持续灾害不会被后到风水治愈、库存变动|

## 依据与明确近似

[官方PC手册](https://cdn.akamai.steamstatic.com/steam/apps/628070/manuals/32sangokushi11wpk_manual.pdf?t=1516151052)：正文10—11页军团/年度周期与灾害、移动说明ZOC、26—27页毒泉和计略、37页军团方针、PK19页指定运输据点。按手册修正伏兵气力为10，同讨20、妖术/落雷50。

[特技资料](https://w.atwiki.jp/sangokushi11/pages/13.html)补充各特技的作用、适用兵种、铁壁保留协攻部队行动、异族保护边界和威压治安门槛。该资料是社区参考，非指定PC补丁的可执行程序实测。

以下仍是工程参数，不声称原版数值：军团编制/重编/撤销消耗20行动力、最多七个委任军团、每团每旬60行动力、每城最多四次城务扫描；运输保留5000金/40000粮、每次上限3000金/20000粮；出兵4000与携粮12000，守军至少10000。军团不支持原版全部委任细项及完整电脑军团层级，分组连通性使用当前地图可通行路径检查。

ZOC采用停止移动的离散预算实现；移动力尺度仍是现有小沙盘尺度。毒泉每次通行或驻留损兵5%，最低保留1兵；运输最低0兵。齐攻每参与队0.65倍伤害，主攻0.5倍反击；掎角50%。同讨伤害系数1.0/0.5。妖术与落雷基础成功率为`50+(己方智力-目标智力)/2`，限制5—75%，防御免疫优先；不受虚实/神算的必中影响。落雷直接伤害为`500+智力*12`，建筑与火场采用本工程规则。上述均待原版精确测试。

蝗灾/疫病持续3旬，逐旬损失对应库存10%和治安3；设施破坏/伤病分支20%。季初疫病4%，除十月外季初蝗灾4%，七月丰收10%/祈愿30%，额外增加当季收入。贼患安全门槛80/威压60，以下发生率`(门槛-治安+1)/2`，最高40%；营寨兵力3000—6000，每月减少城池1000粮和5治安，25%破坏一项设施。营寨目前自主管理其兵力并攻击邻接部队，**没有完整原版异族独立出阵军队AI**。随机事件使用单独保存的整数随机序列，不改变旧战斗随机流。

论客目前处理标准规则下被拒绝的同盟/停战，无可用代表时仍拒绝；超級20%触发、俘虏交换外交和完整使节旅行尚未实现。
