# 原生产规则接口与兼容边界

ProductionCommand 保留单武将构造器，新增 1—3 武将 ID 数组构造器；构造和读取均防御性复制，officerId 为首执行者。ProductionPreview.effects.actors 为不可变逐人结果，包含 acted、XP/current 与功绩；effects.experience 保留首执行者兼容投影。

preview 在当前 StateToken 上只读，不消耗规则 RNG，不写保存、不发送事实；execute 重验全部执行者、费用、库存与设施，成功一次增加 revision 并发布一次 PRODUCTION_COMMITTED。陈旧会话/版本、HOST_BUSY、错误联合类型、重复/不存在/敌方/忙碌武将按现有结构化错误拒绝，失败无副作用。UI/声音仅消费已提交事实，不反写规则。

新局在能力和月行情初始化后显式开启生产来源模式，保存为 v36。v31—33 保持旧能力数值语义，v34/35 保持各自旧生产策略；不得补填来源模式、反推 base 或转移单位。v36 将价格、城市类别字节、任务策略、全部执行者和占用设施显式保存；重复执行者/设施、计时不一致或缺失设施拒绝，不静默修复。

普通生产先逐人增加智力 XP2，再用当前智力计算产量；能吏/繁殖乘数、设施等级系数、实际库存上限、来源城市标记费用分开处理。延时制造开工无 XP/功绩，完成逐人 XP4/功绩100（上限60000），库存仅增加一件；本项目完整旬推进与存档续行覆盖。旧策略保持原工期和旧奖励。

来源依据与限制：原 EXE 30d33b44、原序列化价格/六类别字节、原普通及延时开始/递减/完成片段。原完整势力回合设施刷新、取消/失守的全部原语义、物理设施45到本项目设施的映射、原势力+a2字段的本地化绑定尚未闭合。当前 facilities45 明确按 false 输入，不猜名称；未将未绑定字段写入技巧。实现这些已证规则不代表所有生产/官方开局全面对齐。
