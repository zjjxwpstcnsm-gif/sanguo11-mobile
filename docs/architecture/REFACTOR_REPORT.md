## Completed production paths

Typed shared recruit/patrol: StrategyUi -> MainActivity.executeCity -> GameSession.execute; Unity -> stable JNI facade -> AndroidGameBridge -> BridgeSession -> the same GameSession.execute. Rule handlers are the existing World.recruit/patrol, not duplicate implementations. Successful authority commits, including nonvisual changes, own revisions and notifications.

New/load/import world replacement, snapshot capture, save coordination and turn ticket validation moved into runtime ownership. MainActivity binds a detached compatibility view and subscribes/unsubscribes. Application owns the session and retained TurnWork; explicit exit is distinct from page/Unity destruction. Turn results commit before playback. Remaining native operations use lazy token-checked compatibility transactions. World remains the compatibility model facade, not a rewritten rules engine.

Four real core classes moved into map/army packages. Platform save/JNI/data projection responsibilities have concrete implementations under app subpackages. Filament consumes projections, not World. TrialEntry is now a small composition entry with protocol, JNI/fixture transport, display state, sync and diagnostics in separate real assemblies. Existing .meta identities and fixture bytes are retained.
