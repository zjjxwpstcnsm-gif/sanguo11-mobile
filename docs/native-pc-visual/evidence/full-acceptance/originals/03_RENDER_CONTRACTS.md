# 渲染与资产契约

本文件规定行为边界，不要求照着类名制造空壳。存在同等职责的正式类型就扩展/拆分；包名以 R00 源码盘点为准。

## 1. 所有权与线程

权威命令进入已有 GameSession，现状逻辑线程是 Android main Looper；不在本轮把整套游戏换线程。渲染接收单次会话提交后的不可变投影。选择、高亮、镜头等视图状态与玩法状态分开。

Filament 分支维持经验证的 engine owner thread；耗时网格/解码放后台，GPU 创建/上传/销毁回 owner thread。若纯 GLES，GLSurfaceView 的 GL thread 是 GPU 唯一所有者，用有界消息交接；两者不混用。

后台任务必须带 sessionId、worldGeneration、mapRevision、visualRevision、assetRevision 和请求 generation（可合并等价字段）。过时结果直接丢弃并释放 CPU 资源；不能上传到已销毁 Surface。对象池/缓存需追踪 live reference，不能释放仍在帧/回调中使用的数据。

权威事件可能要求不丢失；可视全量快照可以 latest-wins。不要把两种队列混成无限积压。慢帧、暂停、跳过、低画质不得改变命令次数或规则随机结果。

## 2. 地图与坐标

延续真实 `GridLayout -> GridWorldTransform -> Camera`。本包不规定新的 q/r 存储格式、全国尺寸和城市数。源图坐标、存储行列、逻辑 Hex、世界 X/Z、视觉高度、屏幕像素、内部渲染像素必须命名区分。

同一格中心/边界映射要服务：mesh、树木散布、城港关锚点、单位位置、路径、Overlay、编辑笔刷、屏幕拾取。UI 视口裁剪/面板遮挡与动态分辨率不可改变逻辑格选择。

全国逻辑格集合的每个有效格中心都必须可映射且可还原；边界平局规则保持旧实现。VOID/装饰地景不生成可行动格。七格城市各入口依然沿用权威占地，视觉包围盒不改变移动/进驻。

## 3. 连续视觉场

建议职责：`VisualTerrainField`、`SurfaceSampler`、`TerrainChunkBuilder`、`VisualConstraintMask`、`VisualRevision`，可映射现有 TerrainSurface/SceneMesh。

唯一采样源 `H(x,z)`、材质权重 `W(x,z)`、水陆约束 `C(x,z)` 决定各分块网格、法线和地面锚点。单位是项目世界单位，不擅自当真实地理米。高度不是游戏规则。

全局场允许由逻辑地形、区域参数与固定种子派生；山系需要区域连贯轮廓，不只是每格中心叠噪声。不能重建为每格独立球包/圆锥。水、城址、关隘/道路、可通行地带是硬/软约束，明确优先级与过渡宽度。

chunk 边界采用同一 global sample 和至少算法需要的 halo。法线导数、材质权重、路/河 mask 也跨边一致。LOD 采用邻接约束、stitch/skirt 等明确方案；skirt 不能掩盖物体/拾取高度错位。

拾取应命中**实际显示表面或误差可控的同源表面**；地形可见三角面与求根的高度场不一致时，必须处理误差，不能直接地平面反投影。

## 4. 材质/色彩

颜色贴图按 sRGB 解码，权重/法线/高度等数据图按 linear；最终画面只做正确次数的传递转换。各 diffuse 权重非负且归一化，零权重有确定兜底。

world-space UV 与受控多尺度细节消除格子拼贴；宏观区域色和微观细节独立，不让纯噪点替代真正地表纹理。常规 4 层基线可用，新增层前检查采样器/带宽，不把 8 层全套贴图堆成移动端重材质。

Filament 使用匹配版本离线 matc 与合法 material 语言；纯 GLES 才使用 `#version 300 es` 顶点/片元程序。不要把 GLSL Shader 直接当 .filamat，也不要让实时运行时动态编译依赖大型编译库。

## 5. 资源约定

资源 ID 独立于文件名，可追踪 source、license、checksum、version、LOD、bounds、pivot、单位/朝向、材质、贴图空间、动画、实际使用者。

保留现有资产加载器的已支持子集，不声称一个简单 JSON parser 等于完整 glTF。现有不受支持扩展在离线阶段烘焙/转换或明确拒绝；进入游戏不能静默丢材质/骨骼。

骨骼或刚体部件动画择适配现有路线，不能把刚体摆动命名为“完整骨骼动画”。根运动只表现，真实位置由权威路径决定。所有资源故障有可识别回退和诊断，回退不算最终美术过关。

## 6. 事件与交互

复用 TurnJournal/现有 playback 的正式结果；需要补充展示字段时增加有界、类型化 facts，不重算伤害、不解析中文文本来控制规则。每个特效/音效/数字对应事件 ID 与播放位置，支持取消/跳过/世界替换。

地图标签等二维 Overlay 可以继续使用 Android Canvas；“二维 UI 叠加真实 3D”不是伪 3D。但禁止用一张固定山水图片充当全部地形/建筑来过关。

## 7. 视觉编辑与存档

视觉设置/装饰 patch 与权威地图 patch 分离并具版本；地图逻辑编辑仍走已有编辑器事务/校验。高度、材质、树种/密度等纯视觉改变不应迫使旧存档重开。

缓存键需覆盖地图内容、显示字段、资产与生成器版本，不能仅凭存档名/相机位置。导入需限大小、数量、路径和递归；拒绝远程 URI、路径穿越与压缩炸弹。视觉数据损坏允许回退默认外观，不能损伤原存档。
