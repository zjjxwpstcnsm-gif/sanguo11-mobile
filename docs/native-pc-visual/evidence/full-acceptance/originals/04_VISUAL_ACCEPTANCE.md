# PC 风格视觉验收｜不是编译验收

## 1. 目标与边界

目标是 Android 正式游戏中的连续山河、古代建筑、部队编队和协调的彩墨风格；不是每格一个彩色模型，也不是重做 PC 游戏玩法。本包不承诺像素级复刻，不把推测的地形算法说成 KOEI 已公开的实现。

必须分清：公开资料支持的原版特征、从截图观察出的外观、项目自选的实现方法。例如本路线采用高度场、材质混合和分块，不代表已经证明原版内部恰好使用相同数据结构。

## 2. 参考集与可比性

R00 开始建立参考索引，R04 完成首组有效对照，R09 形成局部完整场景，R15 扩展全图。优先用用户拥有版本的合法截图/录屏或官方/开发者公开截图。参考不足就明确缺项；本包没有附带 PC 游戏资源或原版截图。

每份参考记录：referenceId、来源、PC 版本/平台、区域、日期/季节、镜头方向/缩放近似、画面分辨率、用途/权利说明。无法确定的字段标 UNKNOWN，不编写。

至少覆盖：平原农田、山脉峡谷、河港岸线、城池近景、森林道路、关卡瓶颈、荒地沙地、军队交战；选区以实际地图和参考可得性为准，不擅改地图凑场景。

App 对照必须记录：代码 SHA、APK hash、存档/剧本、区域/中心格、相机、季节、画质、设备/图形驱动、网格/势力开关、UI 是否隐藏。同区域近似构图，不强行要求不同分辨率像素匹配。

同一区域交付至少 3 个缩放档、2 个方向；需要展示自遮挡/空间层次时附旋转或移动录屏。必须有网格关闭/开启对照。

## 3. 分项合格标准

| 项目 | 合格观察 | 不合格示例 |
|---|---|---|
| 地形轮廓 | 山脊连贯、谷地合理，城/路与地形有关系 | 每格鼓包、锯齿台阶、孤立圆锥 |
| 地表材质 | 同地貌尺度一致，草土石沙自然过渡 | 一格一色、整张糊成渐变、等距噪点 |
| 河流岸线 | 水面连贯，岸边有浅水/泥沙或岩岸层次 | 蓝色蜂窝、曲线穿陆、河岸裂缝 |
| 建筑 | 城墙/城门/主建筑层级清楚，贴地、比例统一 | 几个盒子、不贴地、门堵住玩法入口 |
| 关港 | 关隘与山路、码头与水面有可信连接 | 关卡悬空、码头立在旱地、船穿岸 |
| 植被 | 成簇有疏密/林缘，避开道路与实体 | 一格一棵同树、盖住目标、严重穿插 |
| 部队 | 兵种与朝向可辨，编队和地形尺度协调 | 静止立方体、脚滑严重、骑兵马像木块 |
| 光照/风格 | 柔和、层次协调，材质不塑料，阴影贴合 | 用全局灰雾掩盖错误、过曝、黑成一团 |
| 操作可读性 | 关网格像山河，开范围能明确行动 | 把可走平地画成悬崖、颜色覆盖淹没细节 |
| 时序稳定 | 平移缩放无闪烁/拼缝/突然整片弹出 | LOD 裂口、植被随机跳、阴影剧烈闪动 |

每项用 PASS/FAIL/PENDING，并附具体图号与缺陷位置。图像相似度、SSIM、颜色直方图只能辅助排错，不得声称自动数值证明“100%像原版”。

## 4. 视觉里程碑

**V0 / R00：可见且可操作。** 实际全国剧本打开、新 3D 路径有地面/实体、可移动镜头；纯背景不通过。此时允许旧低质资源。

**V1 / R04：地形不再像色块拼图。** 至少一块跨多个 chunk 的真实区域关闭网格后连续；近/中/远景无明显格子材质边界。没有建筑精修不等于最终视觉合格。

**V2 / R09：可用的局部完整美术样板。** 同一个区域中地形、水、城港关、树林/道路、光照能共同成立；是正常游戏内场景，支持真实命令。任一主元素仍为明显占位则不可过 V2。

**V3 / R15：全图风格覆盖。** 所有区域都采用同一合格体系；全图巡检加代表区实拍，不靠只拍最漂亮的一座城。

**V4 / R18：最终 PC 风格对照与游戏体验。** 合格设备的正常画质下完成全流程，所有关键视觉失败关闭；参考不足/真机缺失仍明确标未完成。

V1、V2、V3 是禁止“先无限铺量，最后再美术”的门槛；工程之外无真机时仍可开展独立工作，但不能自动宣布 V4。

## 5. 证据真实性

保留原始截图/录屏和 logcat。对照拼图允许制作，但标清 PC 来源和 App 设备；不能改变 App 内容、补光、替换背景来假装实机质量。

性能截图不能来自不同画质/更低内部分辨率却不标注。不能仅用载入后静态一帧证明回合、动画、热稳定或编辑正常。调试模型展示页可辅助，不代替正式地图验收。
