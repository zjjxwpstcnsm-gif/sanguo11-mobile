# 正式资源生产与接入要求

## 1. 资源不是提示词，也不是文件计数

阶段必须得到真实模型/贴图/材质文件，接入正式地图，保留可再生成的源文件或脚本，并做 APK 实拍。写“后续用 AI 生成”不算制作完成。复用旧资源时写清哪些继续使用、哪些真正替换、哪些仍是占位。

公开 PC 截图只作参考，不自动拥有对 PC 游戏模型/贴图的再分发权。新资源采用原创、用户有权提供、许可清楚的素材。许可证未知不进入正式分发包。不把 AI 生成写成官方原版资产。

工具可用性在 R00 查明：现有脚本、Blender CLI 或可用建模工具、图像生成/纹理工具、离线材质编译器。美术工具缺失可先修技术/制作可复用小样，不能用几个立方体宣称美术完成。

## 2. 资产清单

每个实际资源/资产族记录：ID、类别、路径、来源/作者/许可、source hash、导出工具和版本、runtime hash、贴图尺寸/色彩空间、三角形数量、材质/primitive 数、LOD、锚点、朝向、占地外观、动画支持、正式场景使用位置与验收图号。

每个权威城/港/关、设施类型/等级和兵种都能映射到有效资源；缺失的类别显式列出。不要硬编码“42 城/87 据点”等旧数量作为当前全覆盖，实时从官方/自定义地图读取。

源素材、build 输出和运行时资源分目录。大的录屏/APK/中间产物放 CI artifacts，不把一堆重复历史包塞 Git。不可依赖模型会话沙箱内、其他 Agent 取不到的路径。

## 3. 地表与环境

基础草、土、岩、沙需有协调色板与可平铺纹理；适当增加路径、泥岸、农田、林下材质。贴图去掉固定方向强光/硬阴影，避免叠加照明后双重阴影。

先建立同一 texel density 和宏观/微观纹理尺度，再做变体。正常场景看见的是纹理、轮廓和明暗共同作用，不是简单高分辨率噪声。低画质也保留材质层次，不能降成纯色棋盘。

植被使用少量高质量家族和受约束的变化，不强制一棵一个渲染实体。透明叶片要测试裁剪/排序/过绘与远景闪烁；可用不透明低模/烘焙 impostor 等更合适方案。

## 4. 建筑与设施

城市：城墙、城门、角楼/城楼、主建筑、民居密度和地基分层；城区不是密集同一个小盒子。建立平原、山地/盆地、水乡等至少三类可辨风格，差异服务实际地区，不能随意替换地理。

关卡：有封堵山口的视觉意义，墙体端点与山体衔接；可通行入口保持清晰。

港口：泊位/栈桥、岸上建筑和水上部分连接；锚点、水位与真实上下船格相容。

设施：覆盖所有实际类型/等级、建造中/完成/损毁表现。受损外观只读实际耐久/事件，不能新加建筑规则。

## 5. 部队和动画

覆盖实际使用的步兵武器、骑兵、器械、运输和船只。按兵种建立形体与旗帜识别，LOD 中仍能辨认。

已有刚体分部件动画可以保留并提高资产/轨迹质量，不强制为“高级”改成完整骨骼系统。确需骨骼时再扩展导出/加载/测试支持；每个阶段明确实际技术。

移动/攻击/受击/待机、骑兵腿和器械轮轴/投射、船桨等应与正式事件时序匹配。不要全屏每一名士兵都独立 draw/上传整网格。禁止把模型根运动用于玩法位移。

## 6. glTF / GLB 边界

优先延续当前加载器支持的受控子集；必要时离线转为经过版本化的运行时格式。写明支持的 accessor 类型、index 宽度、stride/offset、node transform、normal/UV、alpha 和动画/扩展范围。

输入先验证大小/数量/索引/数值有界；不支持的 required extension 必须明确报错或离线转换，不能“尽量读”后静默丢部件。防止外部 URI/path traversal；导入资源不能无条件访问网络。

Khronos Validator 检查格式合规；项目检查器再验证受控子集和预算。两者不能替代美术检查。上传 GPU 前资产应通过可复现检查；不可把索引越界留到 native crash 才发现。

## 7. 预算初值（项目目标，不是实测保证）

优先用屏幕占比和场景总预算定资源，而不是单模型一味精细。R06 建立清单，R16 用实际设备调节并解释。

- 代表性城池 LOD0 起始目标不超过 15k 三角形；LOD1 约 30%–50%，LOD2 约 5%–15%；少量焦点城市可例外但必须有预算依据。
- 每个静态资产族优先 1–3 个实际渲染 primitive；不能只看文件数量声称 draw call 少。
- 常规树族采用数百三角形量级起步、集群/远景代理；实际透明过绘比三角形更值得监控。
- 贴图 512–1024 起步；英雄资产必要时 2048，必须有 mip、合理压缩/回退。ETC2 为 GLES3 基线可用格式；ASTC 只能在检测支持后用。

预算可有理由调整，但不能通过把所有城市简化成方块过性能关；必须同时过视觉门槛。
