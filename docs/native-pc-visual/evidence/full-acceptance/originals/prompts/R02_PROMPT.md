## 本阶段目标

让连续 3D 世界能够稳定浏览和操作，同时严格保持原有格子、七格城市和所有命令语义。

## 必读源码与输入

读取 R01、GridLayout、GridWorldTransform、SceneCamera、TerrainSurface.pick、MapHost/触摸分发、UI 面板占区与现有编辑坐标链。

类名/目录仅作定位，必须查到真实文件与运行入口；不存在的路径说明并找对应职责，不能造空文件假装已有实现。

## 必须实际实施

1. 明确 source grid、存储行列、Hex、world X/Z/Y、view pixels、render pixels 变换；沿用已有交错/转置/偏移约定，建立当前全国有效格中心金样本与负坐标/边界样本。
2. 在真实相机内实现平移、锚点缩放、有界倾角和连续旋转（若旧 UI 只翻转方向，升级为可控旋转并保持旧快捷行为）；默认使用参考驱动的策略视角，不凭空声称 PC 的精确 FOV。
3. 使用实际场景 ray 与同源地形/水面/模型选择规则，替换仍然只用平面逆投影的路径。明确最近可见命中、地面格定位和遮挡优先级；远处山背后的格子不能穿透误选。
4. 统一城市七格、部队实际/动画展示位置、港口水面和设施标签的 picking；视觉包围盒只用于选择辅助，不扩充权威占地/射程。
5. 面板/状态栏/刘海/安全区不接收地图命令；区分单击、拖动、双指、长按和双击，拖镜头不能误发攻击。保留“先选部队，再下命令”的现有体验。
6. 动态分辨率/横竖屏/视口改变时保持相机焦点和选中对象，内部 buffer 缩放不改变触点含义。相机配置与存档/规则分离，3D→2D→3D 可恢复。
7. 给诊断加入世界点、格坐标、拾取表面/高度/实体和相机状态；调试层默认关闭。

## 必须验证

- 所有有效格中心投影/反投影；代表性边界、负坐标、VOID、行列转置、七格城市入口回归。
- 至少 3 个缩放档 × 4 个方向 × 3 个倾角的自动格选择抽查；展示 LOD 与拾取误差有明确上限。
- 点击坡顶、山后、水面、港口、移动中部队和 UI 边缘；实际命令与原 2D 验证一致。
- 0.7/0.85/1.0 内部分辨率或项目等价档位下，同一 view-pixel 触点选择一致。
- 录屏显示浏览、选军、移动/攻击预览、切换 2D 后状态不变。

仍需执行全局要求的受影响玩法/架构回归、实际 Android 构建与本阶段图形运行。继承失败和新失败分开，不能删除断言、跳过受影响用例或把 NOT_RUN 写为 PASS。

## 通过门槛

镜头可浏览、拾取不误导、命令未重复；不能仅靠平面数学单测证明实际高低地形命中正确。

构建成功≠运行成功；模拟器通过≠真机通过；有模型≠美术达标；截图有颜色≠PC 对照通过。缺实际参考/资产/设备时继续完成可做工作，但状态诚实保留 PARTIAL/BLOCKED，不把计划当完成。
