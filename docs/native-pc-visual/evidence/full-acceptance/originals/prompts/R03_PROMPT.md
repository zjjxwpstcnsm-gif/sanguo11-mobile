## 本阶段目标

把表现从格子拼接升级为共享高度/法线场的连续山脉与平原，但不改变全国逻辑地图。

## 必读源码与输入

读取 R02、已有 TerrainSurface/SceneMesh/Ground 生成、S10/S11 地形场、地图修订/编辑增量机制、现有 LOD 与缓存预算。

类名/目录仅作定位，必须查到真实文件与运行入口；不存在的路径说明并找对应职责，不能造空文件假装已有实现。

## 必须实际实施

1. 审计现有连续场仍呈现棋盘/阶梯的原因：采样依格量化、格中心鼓包、边缘约束、材质边界还是资产遮盖。只修改确有问题的部分，不重建已经共享的分块系统。
2. 建立同源全局高度场 H 和约束层：水面、城池基础、道路/关隘可走带、地图有效边界；区域山脊/盆地参数可复现。噪声只作细节，不把随机噪声当山系设计。
3. 以连续 X/Z 采样网格或现有网格的连续化实现正式地形；分块只是加载单位。跨块边缘使用全局采样与必要 halo，法线也跨边统一；不能每格独立法线/凸起。
4. 城池地基平整采用受限局部过渡；道路/关口保留可读通路，水域/港口保持既有拓扑。保留可行动格中心与视觉地形一致；修视觉不改 source terrain、城港关坐标或兵种地形规则。
5. 实现近/中/远地形 LOD、邻块级别约束与接缝处理，保持表面锚点/拾取同步；不能一次缓存全国所有精度网格。
6. 局部 patch 只失效受影响 halo；缓存键包括 map/constraint/generator revision；worker 可取消，上传分帧，摄像机移出后优先级下降。
7. 地图外和 VOID 可加不可交互远景补全，但与玩法格严格分离；不能让背景变为可选择的虚构大陆。
8. 在一个真实跨块代表区实拍山脉/谷地/平原改造前后，并输出关闭网格视角；对未平滑的硬约束边界明确记录后续 R05。

## 必须验证

- 分块共享边顶点/高度/法线/材质坐标一致；LOD 邻接组合无 NaN/索引越界/可见裂缝。
- 地形单点编辑后，未受影响块 identity/hash 不变；变化只限约定邻域。
- 全地图逻辑地形、可达性、据点坐标、占地、规则 RNG 哈希与基线一致。
- 城门/港口/关隘路面可实际走；拾取与渲染表面一致，近远 LOD 不使单位突然升降。
- 实际 APK 连续拖动跨块/缩放，观察无孔洞、山体周期性跳变或大面积加载停顿。

仍需执行全局要求的受影响玩法/架构回归、实际 Android 构建与本阶段图形运行。继承失败和新失败分开，不能删除断言、跳过受影响用例或把 NOT_RUN 写为 PASS。

## 通过门槛

地形几何连续且可玩；允许暂用 R00 材质，但不能用纯色贴图模糊几何问题。若实际地图仍每格山包，阶段不可 PASS。

构建成功≠运行成功；模拟器通过≠真机通过；有模型≠美术达标；截图有颜色≠PC 对照通过。缺实际参考/资产/设备时继续完成可做工作，但状态诚实保留 PARTIAL/BLOCKED，不把计划当完成。
