## 本阶段目标

让关网格后的地面不再是一块绿、一块灰、一块蓝，并完成第一道实际视觉对照门槛。

## 必读源码与输入

读取 R03 与已有 ground material、4 层纹理、S10 颜色空间/法线/全局权重场、资产清单和参考索引。

类名/目录仅作定位，必须查到真实文件与运行入口；不存在的路径说明并找对应职责，不能造空文件假装已有实现。

## 必须实际实施

1. 检查当前四层材质为什么仍出现补丁：权重边界、世界 UV 尺度、过强色差、纹理周期、法线/曝光错误分别定位，不能只再增加一张噪声图。
2. 为草/土/岩/沙生产或合法取得实际可平铺贴图并统一色板、尺度与细节；补最必要的林下/泥岸/农田表现时控制采样成本。旧纹理可复用，但证明其视觉质量，不靠改文件名。
3. 完善全局非负归一化权重、坡度/高度/区域约束与平滑过渡；不要把硬性水陆/城路约束一起高斯模糊。各类地貌仍应可辨，不能全图混成同一泥色。
4. 使用 world-space UV 与宏观低频颜色/受控细节去重复；跨格/块同一尺度。法线、roughness、数据图保持线性，颜色贴图 sRGB，检查输出编码不重复。
5. 配合当前后端正式材质实现，Filament 用同版本 matc 离线编译，纯 GLES 用对应 GLSL；将源码、编译脚本、hash、实际加载路径写清。
6. 低/中/高画质保持相同地貌身份；低档可以省法线/细节，不能退回整块纯色棋盘。测量新增采样、上传和纹理内存估算。
7. 选真实跨块场景做至少草土/山岩/沙地/农田过渡对照；完成 V1 的 PC 参考与 APK 原始截图，记录尚缺的建筑/水岸元素，不夸称整体 PC 效果已完成。

## 必须验证

- 权重非负/归一化/全零兜底、边界共享、UV 连续、mip、色彩空间和质量分档测试。
- 相同地区近/中/远景、至少两方向，移动录屏无强烈棋盘、重复波纹或纹理闪烁。
- Shader/材质在实际设备或声明的模拟器后端可创建/绘制；失败不能静默回 unlit 而声称通过。
- 材质变化不修改 terrain type/map hash/行军与战斗结果。
- 与基线比较资源/包体变化并记录，有 reference 缺失则明确阻塞视觉对照。

仍需执行全局要求的受影响玩法/架构回归、实际 Android 构建与本阶段图形运行。继承失败和新失败分开，不能删除断言、跳过受影响用例或把 NOT_RUN 写为 PASS。

## 通过门槛

V1：真实 APK 跨块地形在关网格时不再有明显逐格纯色补丁。代码能混合不等于效果过关；仍像棋盘就继续修。无 PC 参考不能宣称 PC 对照通过。

构建成功≠运行成功；模拟器通过≠真机通过；有模型≠美术达标；截图有颜色≠PC 对照通过。缺实际参考/资产/设备时继续完成可做工作，但状态诚实保留 PARTIAL/BLOCKED，不把计划当完成。
