## 本阶段目标

以实际模型、材质和正确地形结合改善据点与设施，而不是只把占位模型换成更多立方体。

## 必读源码与输入

读取 R06 资产规范、当前 SiteVisual/SiteGlb、据点资产映射、真实七格城市与一格港关规则、设施类型/等级枚举和现有自定义据点接口。

类名/目录仅作定位，必须查到真实文件与运行入口；不存在的路径说明并找对应职责，不能造空文件假装已有实现。

## 必须实际实施

1. 从正式地图/剧本/自定义数据汇总所有实际据点和设施类别，不硬编码旧统计。建立每个对象到资产族/地区变体/等级/损毁状态的可验证映射。
2. 制作或提升城池模型：城墙、城门、角楼/主楼、内城建筑密度和地基结构；至少三类区域风格的轮廓/屋顶/布局有实质差异。可共享模块，不允许全图同一方盒换旗色。
3. 为港口制作岸上建筑、码头、栈桥/泊位；为关卡制作墙体/门洞/山口连接；外观朝向由真实岸线/通道和约束决定，不随机摆向水外或封死道路。
4. 所有基座贴合连续地形，城市平整区边缘自然过渡；超出权威占地的装饰不形成虚假可行动区域，也不遮住周围可走格/港口上下船口。
5. 改善现有内政/军事设施全类型/等级模型与贴图；实际建造中、完成、受损/火烧/摧毁由现有状态驱动。不得新增生产/伤害规则。
6. 统一地图尺度、texel density、旗帜/势力标识与远近 LOD；远景轮廓可读，近景不暴露严重穿插。阵营改换只更新显示参数/旗帜，不重复创建整个 terrain。
7. 实现全量覆盖检查、资源缺失诊断与默认族兜底；自定义新增据点也能用正确资产族。清楚列出仍为临时资源的 ID，不能藏进“兼容模型”。
8. 为普通平原城、水边港、山口关和至少两种设施做 PC 对照与 APK 多角度实拍，记录比例、地形接缝和轮廓缺陷。

## 必须验证

- 当前全部据点/设施映射无空引用，资产通过规范与预算检查。
- 城市七格六向出入/攻击/进驻、港口上下船、关卡通过的权威结果不变。
- 据点新增/移动/类型修改/删除/易主/受损/读档后正确显示并释放旧资源。
- 实际相机近中远与多个方向检查地基悬空、屋顶黑面、LOD 跳变、码头穿岸。
- 在至少一个真实城港关组合区域内运行，不以单独 model viewer 代替。

仍需执行全局要求的受影响玩法/架构回归、实际 Android 构建与本阶段图形运行。继承失败和新失败分开，不能删除断言、跳过受影响用例或把 NOT_RUN 写为 PASS。

## 通过门槛

主建筑轮廓与贴图达到 04_VISUAL_ACCEPTANCE 的局部质量要求；全覆盖可先共享合格资产族，不要求每城独一模型，但明显占位资产必须明示且相关项不可 PASS。

构建成功≠运行成功；模拟器通过≠真机通过；有模型≠美术达标；截图有颜色≠PC 对照通过。缺实际参考/资产/设备时继续完成可做工作，但状态诚实保留 PARTIAL/BLOCKED，不把计划当完成。
