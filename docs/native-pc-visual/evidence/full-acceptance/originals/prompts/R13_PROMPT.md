## 本阶段目标

让正式地图编辑和自定义内容在连续 3D 中可用，并且视觉参数变化不会破坏旧存档或权威地图。

## 必读源码与输入

读取 R12、现有地图/武将编辑器、custom map/patch 导入导出、SaveCodec、SessionSaves、地图 revision/cache 机制，以及已有 S07 视觉属性支持。

类名/目录仅作定位，必须查到真实文件与运行入口；不存在的路径说明并找对应职责，不能造空文件假装已有实现。

## 必须实际实施

1. 逐项核验既有地图编辑：地形笔刷、城港关新增/移动/修改/删除、撤销重做（已有则保留）、保存自定义地图、新开剧本实际游玩和增量 patch 导入导出。不能只保留编辑 UI 不更新正式 3D。
2. 笔刷/选区与 R02 拾取、R12 Overlay 同源，倾斜/旋转视图不误刷；UI 面板/手势切换不漏编辑。提交通过已有编辑事务/校验，不让 renderer 直接改 World。
3. 完善编辑后的有界增量更新：地形高度/材质、水岸/连通分量、道路/植被、建筑地基/朝向同时失效，旧任务被 generation 拒绝，未受影响块保持缓存。
4. 为实际需要的纯视觉参数提供版本化记录：区域 profile、视觉高度/材质覆盖、装饰 seed/密度等。复用已有存储，不新增无用的第二套编辑器；逻辑 patch 与 visual patch 区分并共享明确地图指纹。
5. 保留普通/旧版/自定义存档及武将自定义/头像导入内容。纯视觉版本升级不能强制重开局、搬动城市或覆盖旧存档；视觉数据缺失/损坏可回默认风格，原游戏数据不损坏。
6. 导入导出设置大小、数量、版本/枚举、路径/URI 和数值边界，拒绝不支持/恶意输入；原子保存，失败不能留下半份地图或污染会话。
7. 测试新建自定义城/港/关在 3D 资源映射和玩法中的真实可用性，地图更名/复制/不同剧本重用不会碰撞缓存键；自定义武将不因渲染改造丢属性/关系/头像。

## 必须验证

- 地形编辑、全部据点 CRUD、连续撤销/重做、导入导出、关闭重开、作为新剧本游玩的端到端矩阵。
- 2D 编辑→3D 看、3D 编辑→2D 看一致；权威 patch 结果不受视角影响。
- 旧存档/自定义地图/武将覆盖与头像导入回归，失败导入不修改现有会话。
- 修改一格只重建必要 halo；频繁拖笔刷不积压无界 worker 或把旧结果覆盖新编辑。
- 断写/超限/未知版本/路径穿越/损坏视觉数据安全拒绝或明确回退。

仍需执行全局要求的受影响玩法/架构回归、实际 Android 构建与本阶段图形运行。继承失败和新失败分开，不能删除断言、跳过受影响用例或把 NOT_RUN 写为 PASS。

## 通过门槛

编辑后的自定义地图能真实开局和游玩，旧数据不丢；只显示编辑预览却未保存/未接新剧本不得通过。

构建成功≠运行成功；模拟器通过≠真机通过；有模型≠美术达标；截图有颜色≠PC 对照通过。缺实际参考/资产/设备时继续完成可做工作，但状态诚实保留 PARTIAL/BLOCKED，不把计划当完成。
