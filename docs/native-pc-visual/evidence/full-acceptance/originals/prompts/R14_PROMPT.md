## 本阶段目标

统一地形、建筑、植被、部队和水体的美术语言，并让已有时间/季节驱动环境，而不是只套一层滤镜。

## 必须实际实施

1. 从 V2 对照归纳统一色板、明暗层次、材质粗糙度、轮廓与远近景层次；明确项目自选艺术实现，不宣称原版内部 Shader 的精确算法。
2. 在选定后端完善柔和方向光/环境填光，统一地形与对象材质响应。阴影优先稳定且经济的方案，控制 acne/peter-panning、远景闪烁与边界；低档可用合适简化，但不能全部悬浮无接地感。
3. 彩墨处理优先来自资产与材质，结合适度调色/轮廓强化/距离或高度雾；避免全屏重描边、塑料反光、纯灰大雾和过曝。UI 和数字不被世界后处理染糊。
4. 雾层/云层按深度、距离与场景约束实现，不能遮住主操作区、掩盖接缝/缺模或让近景与 PC 对照不可比；记录透明过绘成本和低档策略。
5. 四季由现有日期/季节投影驱动，统一地表色、树叶/农田、环境光与必要雪覆盖；变化不得改变 water/terrain type、行军/收入规则，不能每旬重载全国全部资源。
6. 季节读取/跳转/读档后状态一致；调试强制季节只属于显示测试，不反写权威年月。仅在参考/原有规则支持时表现冰雪，不因视觉冻结河面改变通行。
7. 增加稳定的艺术 profile/参数校验和截图基线，三画质保持相同风格，性能降级不把整个世界回退为普通纯色低模。
