## Audit and production changes

Normal MainActivity → MapHost → FilamentMapView path now requests a bounded
terrain window with 16-unit prefetch and 12-unit movement slack. One cancellable
SceneWorkQueue holds requests; pending work completes before a changed camera
requests another window, so continuous dragging cannot starve completion.
Nearer chunks build first. GPU uploads retain the two-mesh/frame budget; existing
visible levels remain until replacement upload, then retire. This is a count
budget, NOT a measured 2ms limit. Camera-only updates retain the scenery GPU.

TerrainSurface v3 uses a compact Wendland kernel (radius 3.4) with zero derivative
at sample centres; the prior radial cubic kernel had a centre cusp. Hard water,
site and path constraints remain, but their release slope is now a 4.5-unit
smoothstep instead of a constant-gradient ramp. The minimum of constraint caps
can still form derivative creases; no claim of fully smooth shores. Existing
world ridge parameters (.16x+.11z+.7sin(.08z), height 1.6+.9ridge) remain reproducible.
Noise is not substituted for mountain design. Half-unit sample cache is bounded
at 32768 entries, clears on saturation, and does not affect deterministic values.

Three production LODs keep the same canonical fan planes and edge vertices:
8 / 24 / 72 triangles per logical cell. Interior planar subdivisions improve
material interpolation only, NOT terrain silhouette. All levels therefore have
zero anchor/pick displacement and need no skirt. Chunk-centre Chebyshev distance
bands of 32 units keep source-neighbor levels within one; span floors are 14/40.
Only the requested level is retained per chunk. At national overview many coarse
chunks are legitimate; it does not retain all national precision levels.

Production fingerprints include map identity, local terrain/site/paint halo,
layout and generator/material/water versions and LOD. They no longer include a
monotonically increasing global mapRevision, which had invalidated the whole map
on a local patch. Ground.matches still detects revision updates to request new
work. Legacy whole-map audit overload keeps its original seed-invalidation
contract. Vegetation retains its existing version-dependent seed contract; changing it
failed the independent FieldAssetsTest in CI35869690421. The new failure was
fixed in production without deleting/changing that assertion. Its dependency
halo expands to eight source cells, but it still retains whole-map CPU meshes
and reseeds on mapRevision: explicit remaining memory/incremental-update debt.
