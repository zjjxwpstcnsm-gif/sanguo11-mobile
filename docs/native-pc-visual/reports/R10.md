## Production path
Normal MainActivity -> MapHost -> immutable MapSceneSnapshot -> FilamentMapView.
- UnitVisual maps all 13 real categories and derives bounded representatives from
  actual troops. Prefix-stable slots retain the leader/survivors through casualties.
- UnitFormation samples each representative's exact terrain anchor and contact
  plane. Ships use the existing water level. Stationary transforms avoid resampling.
- One CPU-cached rigid-part pose mesh is shared across GPU draw instances. The
  version56 compiled unit material applies bounded per-member offset/grade uniforms.
  This is **GPU instanced drawing, not GPU/skeletal animation**; articulation is
  still retained rigid-parts-v1 CPU posing in the asynchronous bounded cache.
- UnitMotion preserves every authoritative path segment and endpoint. Only heading
  blends near a bend. UnitAnimation/formation/HUD share journal hit/phase/loss state;
  naval selection samples the exact displayed path position, not a second pathfinder.
- UnitLod uses 7.2/8.8 and 20/24 hysteresis. Idle quantizes one shared period instead
  of changing animation speed on LOD transitions. Attack phase never restarts.
- Real mesh picking accounts for every instanced member/contact plane, returns the
  stable unit ID; MainActivity resolves it against current session state. Existing
  command/turn locks and target validation remain authoritative. Text allegiance
  and unit ID supplement flags/colors.
- New unit-only woven/lamellar/wood atlas and 26 unit GLBs preserve environment
  atlas/resources. Weapons, horse shin/knee/hoof, whole rotating wheels, engine
  reinforcements, ship gunwale/oar blades enhanced in the original source pipeline.
