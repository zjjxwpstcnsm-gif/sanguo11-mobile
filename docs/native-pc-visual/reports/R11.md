## Production changes and authority boundary
- `TurnJournal` now supplies transient journal/sequence IDs, typed plot/infantry/
  equipment tactics, naval source/strike facts, typed scalar impact amount and
  stable casualty entity key. War/Army edits only append observational metadata
  immediately after existing visual markers. No rule formula/order/RNG/map/save
  change. IDs never enter SaveCodec or consume rule RNG.
- `CombatVisual` dispatches typed facts, not Chinese report strings. Original-actor
  fire/stone tactics are retained while counters use their own weapon/naval facts.
  Actual multi-hit/counter phases remain ordered. Casualty labels use applied
  `Strike` losses plus only the residual actual `Impact` amount, preventing duplicate
  numbers without hiding fire collateral. Displaced targets match stable entity ID.
- Eight shared opaque procedural meshes / 64 reusable particles: tangent-oriented
  volleys and artillery sampled above terrain, cavalry dust, flame smoke, naval
  splash and hit/recovery/status pulses. LOW uses fewer rays/smoke, not fewer scalar
  result labels. No shader/texture/model cohort replacement or runtime compiler.
- Normal `MainActivity.apply` records the already-validated command once, binds and
  autosaves authority, then starts bounded display-only `CombatSequence`. Historical
  immutable `MapSceneSnapshot` preserves a defeated target/auto-garrisoned actor
  while the final snapshot is already committed. Completion/cancellation restores
  the exact current snapshot. No animation callback executes a command or saves a
  display World. Existing critical portrait, reports and haptic remain; no new audio.
- Retained bounded `CombatReplayLedger` prevents finished/skipped/offscreen events
  being played again on camera/view recreation. New command, mode switch, background,
  replacement and release remove the old callback/effects. Normal battle banner long
  press offers pause/1x/2x/4x/skip; next command remains available. Existing turn
  controls now clear critical/effect visuals synchronously on skip, and retain
  announced event IDs across reconstruction to avoid duplicate counts/reports.
- The two additional legacy-core consumers accept only immutable TurnJournal
  payloads. Their reviewed allowlist entries have a dedicated architecture guard;
  they cannot call World/SaveCodec/GameSession/RNG. No game-api/runtime changes.

## Rendering/asset limits
Effects intentionally use opaque depth-tested/depth-writing shared geometry. No
transparent sprite ordering or volumetric smoke is claimed. This avoids sorting
halos but smoke remains stylized polygonal dust. Persistent fires are rebuilt from
published snapshots; paused historical command snapshots intentionally show the
pre-action scene until its presentation finishes. Art is a candidate, not PC parity.
