## 设计规范（移动端适配）

保留现有地图、肖像、原版资源、墨玉底色、铜金与玉色信息层级。控件布局、圆角、响应式面板及触控规范属于移动端适配，不声称原版像素复刻。

- 主背景 `#0c141c`、面板 `#17252f`、分隔 `#30444d`、正文 `#edf3f3`、次要文字 `#a4b6bf`、选中/主行动 `#81e2c4`、章节强调 `#d7bc87`。
- 4dp 间距基元；内部间距 8/12/16dp；主要按钮及列表交互至少 48dp。视觉可紧凑，实际点击区域不能缩小。
- 标题 20–24sp，正文 14–16sp，密集表格 12–13sp；关键信息不能仅靠颜色，需选中状态、文字与读屏描述。
- 面板标题与关闭始终可达；地图目标选择提供目标说明和取消；系统返回与可见返回保持一致。
- 搜索、筛选、排序、空结果、详情统一。错误输入保留草稿并在字段内说明；不可用命令使用权威预览原因。
- 城市分页先于长概览信息显示；执行人确认写明城市与武将。返回修改保留同一名单的查询、排序、滚动和选中状态，读屏说明已选项。
- 普通城市治理与建设确认由权威DTO提供成本、效果和失败原因；失败时禁用正式确认，返回保留草稿。条件检定概率不得写成最终结果概率，建设预计值不等于必然完工。太守/褒奖的执行人页明确“返回目标”，保留候选、勾选与搜索。
- 运输数量范围、库存和目的地空位均由权威DTO提供；超限输入保留原数值，禁止悄悄截断。目的地满仓提示等待卸货，不能把核心允许的派遣改成UI禁止。兵装与舰船独立页签，切换保留全部原输入；条件反馈不挤占整行正文。旅途耗粮与抵达时间标为条件预测。外交区分派遣、抵达交涉与立即解除；首次接受检定不是最终保证。
- 生产区分立即入库、在制与条件完工；展示权威产量/工期/库存/设施剩余次数。商人共用买卖表单，保留数量及执行人，只按allowed开放确认；无效步长/溢出保留原输入，不显示可执行报价。横屏数字输入关闭全屏提取，保证错误与取消仍可达。
- 横屏键盘下，数量名/范围与输入行一起可见，取消和提交保留。狭小视口把页签/说明纳入同一滚动区，键盘收起恢复位置；绘制前仅在可见高度变化时重排，关闭释放监听。
- 真实高成本命令预览后确认一次；查看与筛选不确认。已确认动作防重复提交，局面变化使旧预览失效。
- 地图手势进入面板或离开可见地图后，整次手势取消；不能移回地图继续提交。小地图出现多指后，本次不再导航；下一次单指按下才恢复。失焦/后台/切换渲染器终止未完成的相机与拖放交互，恢复不能补执行旧动作。
- 回合完成入口明确显示已完成并可查看战报；耗时记录区分含暂停/后台的实际经过时间、扣除主动暂停的演示计时和运算时间，不将演示计时作为整旬延迟。
- 显示读取/建立进度，取消后的后台结果不得重开页面。存档失败保留原文件并给出恢复路径。
- 暴击约0.75秒，接受0.5–1秒；当前沿用680ms和原资源；不扩大美术逆向任务。动效尊重系统设置。

## 权威接口边界

UI 继续通过 `NativeGameHost` / `GameSession` 提交命令、捕获存档及接收结果。`LegacyView.draft` 仅作为已有兼容展示，不能形成第二套状态。命令确认以 world 身份 + commandRevision 校验旧预览，执行失败原因来自正式结果。任何新增规则能力先写输入、输出、失败原因、状态所有权和视觉事件契约，由玩法会话实现；本轮不改 core、game-api、剧本、武将数据和内容转换工具。
