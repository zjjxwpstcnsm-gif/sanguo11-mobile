# UI / UX 第一批：读取、列表与触控基础

状态：2026-10-03，47 项安装交互检查通过；完整游戏流程目标仍进行。

## 实现

- 原有墨玉界面和全部游戏美术保留；启动页区分主操作与自定义工具，剧本条目采用名称/规模两行层级，弹窗统一配色。
- `UiReadTask` 将存档目录、载入、剧本与地图准备移出主线程。同一读取不重复启动；取消使旧回调失效，并取消尚未执行的排队任务；Activity 销毁时释放工作线程。
- 存档目录明确空槽与不兼容文件，加载时不能点选不可读项；覆盖仍由用户确认，局面仍经正式会话安装。
- 表格搜索、清除、排序和行保持至少 48dp 交互高度；空结果说明和清除入口适应键盘/短屏。城市外部搜索也可从空结果正确清除。
- 非法页码留在原表单，并在字段下显示错误，避免系统错误气泡挡住取消按钮。
- 横屏 HUD 重排为一行。武将列表在短屏收起独立筛选行，通过“筛选”入口保持全部条件可操作；列组改为下拉，保留列表可见行。
- 势力预览补充尺寸变化时布局重排、信息卡滚动和开局重复确认防护；这些开局增量尚未单独完成安装流程验收。

## 保留的失败与边界

所有历史日志/录像保留在 `out/uiux/iteration-01`：基线演出测试未定义 fixture；测试 runner 清单首项被默认 runner 替换；测试窗口坐标和 TextView 内部滚动偏移导致误触；错误气泡挡取消；初次几何断言只检查行高度而未检查可见范围；短屏裁切。后两项促使加强实际可见高度断言，并修复布局。

`run08/uiux/FAIL.png` 是设备目录沿用的旧失败截图（以原始时间戳区分），不是run08失败；新的通过结论仅对应 `interaction-run08.txt` 与列出的同轮截图。后续证据目录需按运行标签隔离。
