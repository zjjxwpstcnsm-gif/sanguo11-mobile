# 第十七批：地图手势取消与真实生命周期

## 隔离与改动

独立UI目录、codex/mobile-uiux，以13ff5b9为基点，继续冻结AA396/v6 init及402项构建依赖，不追随玩法目录的进行中规则改动。原目录、5554、core/API/runtime/data/内容工具保持只读；地图和原版资源不换、不降画质，不启动Wine。

2D地图在任一触点越出地图或进入遮挡面板时取消整次手势，移回也不会继续拖动或提交。失焦、暂停、禁用和移除时清理相机惯性、缩放识别器及未完成拖放。3D小地图加入第二个触点后锁定取消直到本次手势结束；暂停、禁用、释放时清理识别器和未完成拖放。只管理展示与输入，不执行规则或维护第二套状态。

真实后台测试进一步暴露暂停同步保存开销。MainActivity现在将一次权威capture的字节写入原有原子存档，再用同一份成功保存的字节计算UI恢复提示校验值，不重复捕获、不跨回调缓存World。保存失败不更新UI提示；可选视觉侧文件失败仍保留原来的成功存档及错误反馈。增加capture/write/visual分段日志，没有将权威调用挪到不安全线程。
