原始数据见 `performance-after.txt`，实装结果见 `native-performance.log`。这些是**无 KVM 的 x86 软件模拟器、离屏软件 Canvas 耗时**，不是屏幕 FPS，也不是 ARM 真机耗时；该阶段另一个旧版模拟器仍在运行，不能据此做真机速度承诺或计算新旧提速比例。

旧版第一次测试被模拟器 System UI 无响应弹窗阻挡；第二次在启动前处理该系统弹窗后仍于 1,200 秒超时，应用日志存在耗时数十秒的绘制与触摸积压，摘要见 `baseline-timeout.txt`。没有关闭游戏错误提示或将这次超时标为通过。新版在独立模拟器上，启动前处理同样的 System UI 弹窗后完成验证。

没有 ARM 实体手机验证，不能承诺所有机型固定 60/120 FPS。已移除全图每帧逐格绘制、巨大边界路径提交和显示中位图主动回收等高风险路径；用户设备上所有闪白原因尚不能由本地测试完全排除。
